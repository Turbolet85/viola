- **2026-09-27-instance-state-and-start-order** (tempfile `persist` snapshot writer, start order as landed) — replaced atomic-write-file with tempfile 3.27.0 `persist` through ONE shared helper `viola_state::fs::replace_private` (mode set before the write) and introduced `replace_private_shared` "for identical concurrent writes"; `.lock` siblings opened for write because Windows refuses the lock on an append-only handle; `[Deployment]` + `bin/`: re-hash before reuse, mismatch refuses `pinned-hash-mismatch`, plugin rewritten every start; sha2 became a `viola-state` product dependency.
