## Patterns to follow
- The harness command set stays one JSON document plus a typed exit per command. `gate --require <suites>` stays the per-job verdict step (`coverage,doctest,playwright`; `perf`; `nextest-unit`; `fuzz-replay`), and only the `mutants` / `--mutants-legs` requirement leaves it (per architecture §Infrastructure Patterns → CI/CD approach).
- Separate target dirs because a running exe cannot be relinked on Windows: `target/harness/` for the harness's own builds, `target/mutants/` for the mutation arm. Harness self-tests that nest cargo keep this separation (per architecture §Occupied Resources → Repository).
- Measured-claims wording: architecture.md cites a run or evidence file whenever it states a timing or behaviour (for example the chunk 2026-09-27-epoch-2-cleanup pre-push sizing). The macOS 73 s CARRY is fixed at its cause or measured and recorded in the same way, never asserted (per architecture §Infrastructure Patterns → CI/CD approach, pre-push paragraph).
- Proof scripts accompany gates (`deny-probes.sh`, `lint-probes.sh`, `orphans-check.sh --probe`). Supply-chain gates stay green after the workflow edit (per architecture §Infrastructure Patterns → Build system).

## Anti-patterns to avoid
- Never add a `concurrency:` block to a workflow while dropping the mutation jobs. zizmor's `concurrency-limits` stays declined because a cancel drops a run's `always()` gate and upload chain. That half of the reasoning does not depend on mutation, and its already-retired mutation half needs no new wording beyond the wrap (per architecture §Infrastructure Patterns → CI/CD approach).
- Never introduce a new env var or a configuration channel. `AGENT_RUN_CHUNK_BASE` is described as "the mutation gate's diff base". If the kept `run --mutants` still derives a base, the variable stays test-harness-only and is never read by `viola`. If only the retired gate read it, it is retired rather than left orphaned (per architecture §Occupied Resources → Environment variables; §Cross-cutting Patterns → Config management).
- Never skip the `secret-scan` exact-path exemption for `target/agent-run/chunk.diff` (repository source text) while that file still exists, and never add a new uploaded path under `target/agent-run/` that carries source text (per architecture §Occupied Resources → Repository).
