- **2026-09-25-pty-wrapper-on-windows** — Changed §3 (Keyboard test harness → Tooling) and §6 (CLI equivalent). The zero-viola-bytes clause now means only that viola's own literals are absent, on every leg. The byte-for-byte check against an unwrapped run holds on Linux and macOS only. On Windows, ConPTY emits its own spawn sequences (`ESC[?9001h ESC[?1004h ESC[?25l ESC[2J ESC[m ESC[H`, OSC 0 title, `ESC[?25h`) and re-renders nested output, so the windows-2025 check is literal absence. It must not reintroduce a byte-for-byte oracle on windows-2025. It is also a precedent: a ConPTY behaviour measured on the host became a §3/§6 amendment while §1 (a verbatim a11y-scope copy, D-A11Y-15) stayed unedited. A "document" outcome for H2 should land the same way and must not touch §1's boundary clauses. It also carries "ConPTY swallows focus reports" as a labelled HYPOTHESIS with no measured basis. It is ConPTY-class like H2, but this chunk must not settle or cite it as fact unless the recorder happens to measure it.
