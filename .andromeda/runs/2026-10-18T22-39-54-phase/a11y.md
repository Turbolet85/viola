## Constraints
- The Claude Code plugin (hooks, the stdio MCP server) and the wrapper IPC channel are a not-assertable entity with no UI surface, per a11y-plan §1 A11y Scope Summary (Not-assertable). Neither the precedence reading nor the exit-1 reading adds or owes an a11y assertion.
- The wrapped precedence start (`viola run`, which loads the `--plugin-dir` plugin) is the boundary-only tui entity, per a11y-plan §1 A11y Scope Summary (tui surface). viola writes zero bytes to the terminal except the child's output. Its diagnostics go to `diagnostics/`, never to the terminal. Reading `diagnostics/mcp.ndjson` keeps to that rule. Any output the readings would need from viola on the terminal does not.
- Any key the trust-dialog method types into the pty of a `viola run` start is a human keystroke at the wrapper boundary, per a11y-plan §3 Keyboard test harness. It is not on the closed non-editing list (focus reports, mouse reports, terminal replies). It takes the wheel and must reach the child unblocked. Whether the rig's candidate pty is viola's outer pty or a separate rig pty is research's question.
- A human keystroke is never blocked, refused or delayed past the current atomic paste in `viola run` or a passed `viola revive` start, per a11y-plan §11 A11y Anti-Patterns (Keyboard). A fix the readings force must not change this.
- The `claude agents --json` read behind the MCP `list` call is spawned directly and killed at 5 s. Per a11y-plan §8 Cognitive Accessibility (Timeout extensions), that bound falls on viola's own child only, never on a keystroke or the human. A failed read leaves the board as read.
- The output of `viola plugin install`, which the rig runs, is a pinned fixed copy set, per a11y-plan §8 Cognitive Accessibility (Plain language). The four planning-form lines are pinned by literal, and so is the `--json` document. If P4 forces a fix that changes that copy, the pin is updated on purpose, never loosened.
- No WCAG conformance claim exists for the cli or the `viola run` TUI, per a11y-plan §11 A11y Anti-Patterns (Strategy). The live readings are plugin-precedence evidence and stand in for no SC.
