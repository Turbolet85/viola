## New facts
- F1 · surface · `viola link` / `viola unlink` run the driven instance's strict-modes check before any role file or log opens. A refusal exits 21 with the fixed instance-state `unable:` / `hint:` pair on stderr, or under `--json` exactly `{"v":1,"error":"instance-unreachable","detail":null}` on stdout with stderr empty, and leaves the directory's mode as found.
- F2 · surface · The `since` in `link    <driver> -> <driven>  since <time>` is the reply's `since` printed as UTC clock time in whole seconds with `Z` (`HH:MM:SSZ`). A `since` that is not an RFC 3339 instant (the restore's `unknown`) prints through the message escaper.
- F3 · surface · `viola link --json` prints `{"v":1,"ok":{"since":…,"already_linked":<bool>}}`, and `viola unlink --json` prints `{"v":1,"ok":{}}`, each with exit 0.
- F4 · surface · The names printed in the link / unlink lines are the verb's own parsed arguments, never names read back from the reply or the log.
- F5 · surface · `viola unlink` prints `unlink  <driver> -> <driven>` and exits 0 whether or not the pair was held. The wrapper answers `ok` for an absent pair and appends nothing.
- F6 · surface · Each link / unlink result line is one write, plain ASCII with no SGR in every mode.
- F7 · surface · A wrapper error for `link` / `unlink` (`-32602`, including `driver` equal to `driven`) is exit 20 `error: wrapper fault`. A stopped driven instance is exit 21 with the not-running hint last.
