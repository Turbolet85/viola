## Bindings
- **typography callsign ↔ surface link / unlink names**: the name shape the validator holds (.andromeda/design-system-detail/typography.md:12) is the name `link` / `unlink` print back as their own parsed arguments (.andromeda/design-system-detail/surface.md:105), so a name is refused, never normalised, before it is printed or joined.
- **iconography separator ↔ surface refusal shape and exit codes**: the two-space reason / detail split (.andromeda/design-system-detail/iconography.md:11) is the split of the `[/ ] unable  <name>  <reason>  <detail>` line (.andromeda/design-system-detail/surface.md:21) and of exit 13's detail words (.andromeda/design-system-detail/surface.md:146); the ` - ` field separator (.andromeda/design-system-detail/iconography.md:12) carries the skip counts (.andromeda/design-system-detail/surface.md:36).
- **surface colour depth ↔ surface width**: the environment boundary is the colour facts read only to choose a depth column (.andromeda/design-system-detail/surface.md:8, .andromeda/design-system.md:254) and the width read only from stdout's own terminal (.andromeda/design-system-detail/surface.md:27); the enumeration names both.
- **surface list row escape ↔ message-mode escaper**: `\xHH` for every control in a board row, `\n` and `\t` included (.andromeda/design-system-detail/surface.md:36), against the message mode that keeps `\n` and `\t` for `wait`, `last` and a `link` `since` (.andromeda/design-system.md:315, .andromeda/design-system-detail/surface.md:106).
- **surface hints ↔ exit codes**: refusals at exit 13 carry their hint (.andromeda/design-system-detail/surface.md:55), faults at exit 1 and 20 carry none (.andromeda/design-system-detail/surface.md:81, .andromeda/design-system-detail/surface.md:141, .andromeda/design-system-detail/surface.md:148).
