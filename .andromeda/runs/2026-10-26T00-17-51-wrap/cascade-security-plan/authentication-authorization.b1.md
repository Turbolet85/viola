### authentication-authorization#1.3 · values · auth · ## Authentication & Authorization · lines 14–16
- **Requirement:** IPC access control (Windows)
  - **Implementation:** The listener gets an explicit protected DACL, `D:P(A;;GA;;;<user-SID>)(A;;GA;;;SY)`: the user SID + SYSTEM only. The SDDL string is converted to a descriptor with windows-sys (`Win32_Security_Authorization`), owned, and passed to `ListenerOptionsExt::security_descriptor`. ### authentication-authorization#1.4 · values · auth · ## Authentication & Authorization · lines 17–19
- **Requirement:** IPC access control (Unix)
  - **Implementation:** **Primary control:** the socket lives in a per-user directory with mode 0700: `$XDG_RUNTIME_DIR/viola/` on Linux, `$TMPDIR/viola/` on macOS, and `/tmp/viola-<uid>/` only as a fallback. The endpoint becomes `<dir>/viola-<h12>.sock`. **Directory check:** before bind, and again before any client connect, `lstat` the directory and require owner == `geteuid()`, `mode & 0o077 == 0` and not a symlink. Linux abstract namespace is never used.
