## 3. Design System Excerpt

### Surfaces
- **web-spa** (desktop-webview / browser SPA, `viola ui`) — The single loopback-only page served by `viola ui`, targeting Edge/Chrome on Windows first plus Chromium, Firefox and Safari on macOS/Linux. It is built with Lit light-DOM `viola-*` custom elements over semantic HTML and hand-written layered CSS, with no component library. It is dark only, view-only in v1 (no controls), and verified headless in CI on ubuntu. A11y tool reach: axe-core + Lighthouse + screen reader (NVDA / VoiceOver / Narrator) + keyboard walk. Windows forced-colors (High Contrast) is explicitly styled.
- **cli, human TTY** (cli) — `viola` binary stdout/stderr in Windows Terminal/conhost and macOS/Linux terminals. Output is static fixed-column k9s-style rows, ASCII only, and colour is only a second cue (amber `DIALOG` word, dim `stale` rows, bold NAME). There is no interactive prompt, TUI or pager. A11y tool reach: manual keyboard + terminal screen reader review, with no automated tools.
- **cli, machine / non-TTY** (cli, `--json` / piped / `NO_COLOR` / `TERM=dumb` / `viola run` passthrough) — No colour, no glyphs, no cursor control. `--json` emits one JSON document on stdout. `viola run` prints nothing while the wrapped child TUI runs. A11y tool reach: none (machine consumers). The words carry every state.

### Loading / Error / Empty State Patterns
- **Initial read (before `/api/sessions` answers)** — inline text: each rack prints one ruled line `sessions: no reading yet`, and ATIS fields print `unknown`. There is no skeleton and no spinner, since spinners, skeletons and "Loading…" are banned. A11y impact: the loading state is plain text only. Design does not list it among live announcements, and it specifies no aria-busy.
- **Missing / absent readings** — inline word: a failed reading prints `unknown` in its field box, and a field absent by contract on unwrapped strips prints `n/a`. Fields are never blank. A11y impact: the state is always conveyed as text in the cell.
- **Empty rack** — inline text: `no wrapped sessions — start one with  viola run <name> -- claude`, with the command in Code type. A11y impact: static text, not announced.
- **Empty tape** — inline text: `TAPE live since <time> — no events yet`. A11y impact: static text.
- **Tape connection state** — inline ATIS cell words: `TAPE connecting` (lamp-off), `TAPE live since …`, and `TAPE stopped · viola ui not answering`. The stopped cell is boxed, and a strip also appears at the top of the tape. Strips keep their last values and the ATIS age keeps counting. A11y impact: `TAPE stopped` is one of only three things announced through the visually hidden `role="status" aria-live="polite"` region.
- **Cocked strip (dialog pending)** — in-place state on the session strip: the strip is offset out of line, keeps its slot, gets the amber band, and prints `DIALOG <kind>`. A11y impact: it is announced politely ("builder: dialog pending, permission"). Outside the tab, `document.title` becomes `DIALOG <name> · viola` (plus `+N` when several are cocked) and returns to `viola` when none are cocked.
- **Readback states (`open` / `read back` / `unable` / `unconfirmable`)** — inline box plus word cell at the far right of tape send lines and transfer markers. Changes are instant. A11y impact: readback refusals are announced politely ("send to builder unable, not-delivered, no-prompt-submitted"). `open`, `read back` and `unconfirmable` are not listed for announcement.
- **Stale liveness** — in-place instant lamp-off dimming of the whole strip, which keeps its slot and prints the word `stale`. A11y impact: it is not in the announced set.
- **Budget paused / expired window / nonzero skipped** — inline boxed words in the ATIS header (`budget-paused`, `expired`, `skipped N …`). The header can grow downward by a line. A11y impact: static text, not in the announced set.
- **Tape overflow / follow** — inline static text lines: `N new lines below` (a link-styled anchor to the tape end) when the reader is not at the bottom, and an `older lines trimmed from view: N — the full tape is events.ndjson` notice at the top once the DOM line cap is reached. A11y impact: nothing jumps and no auto-scroll happens unless the reader is already at the bottom. Auto-follow and the anchor jump are instant.
- **CLI waiting / progress** — static stderr line `waiting: <name>` (TTY only), and `viola verify` prints appended step-counter lines (`[03/14] … pass`). A11y impact: no spinner, redraw or elapsed counter, so each line is final text.

### User-Facing Error Surfaces
- **Access strip, 401 `unauthorized`** (in-page, full-width strip in the rack position) — appears for: a missing or invalid session cookie. Content is `UNAUTHORIZED  this page has no session for <host>` plus one instruction line to open the `viola ui` launch line or restart. A11y requirements: design specifies no focus management and no ARIA role, and it is not in the polite-announcement set. Recovery affordance keyboard reachable: no in-page affordance (recovery is out-of-page via the CLI launch line). There is no retry control and no input field.
- **Rack error strip, 503 `state-unreadable`** (in-page strip in the rack position) — appears for: the viola home being unreadable. Content is `unable · state-unreadable  viola home could not be read`. A11y requirements: no focus management or ARIA role specified. Recovery affordance: none in-page.
- **Rack error strip, 404 `not-found` / 405 `method-not-allowed`** (in-page strip, defensive) — appears for: unexpected route or method problems. Content is `unable · <problem>`. A11y requirements: none specified. Recovery affordance: none.
- **403 `host-not-allowed`** (browser-rendered Problem JSON, no in-page visual) — appears for: a Host header rejection, where the page cannot load. A11y requirements: outside the page's control.
- **Tape stopped** (ATIS header boxed cell plus a strip at the top of the tape) — appears for: the SSE stream closing (`viola ui not answering`). A11y requirements: announced via `role="status" aria-live="polite"`. No focus move specified. Recovery affordance: none in-page.
- **Readback refusal** (inline in the tape send line and the transfer-marker last-send cell) — appears for: send refusals (`human-typing`, `budget-paused`, `unverified-cli`, `not-delivered · <detail>`, `unknown`). It prints `unable · <reason> · <detail>`, and the full text is also in the line's expanded `<details>` body when truncated. A11y requirements: announced politely via the status region. The accessible name is carried by the word cell. No focus move. Expanded detail is keyboard reachable (yes, via `<summary>` Enter/Space).
- **CLI refusals and errors** (stderr, human mode) — appears for: typed refusals (`unable  <name>  <reason>  <detail>`, prefixed by the `[/ ]` mirror on `viola send`), each followed by one `hint:` line. Also covers faults (`error: wrapper fault`, `error: internal error`) and `viola run` start refusals (`unable: <name> is already live`, etc.). Under `--json` a refusal/error object goes to stdout with a typed exit code and no hint prose. A11y requirements: plain text only, no colour-only meaning, no stack traces. Recovery is a textual hint (no interactive recovery).

### A11y-Relevant Design Tokens

Components use only role-alias tokens. The primitive `--c-*` tokens are read only where aliases are assigned or reassigned (the stale swap). The page is dark only (`color-scheme` dark, no light-mode switch).

#### Color tokens (foreground / background pairs)
- **--ink / --surface-bay** — context: primary ink (session names, field values, tape text, phraseology words, error strip text) on the bay/anthracite surface.
- **--ink / --surface-strip** — context: field values and callsign on a lit wrapped strip (holder surface).
- **--ink / --surface-inset** — context: text in inset cells (DIALOG kind word, open readback box interior, expanded tape well).
- **--ink-dim / --surface-bay** — context: secondary/tertiary/muted text (column captions, timestamps, reading ages, `n/a`, `activity`/`harness` lines, `TAPE connecting`, zero `skipped`, all ink of a `stale` strip). Design restricts it to anthracite only: it measures below the SC 1.4.3 4.5:1 threshold on the holder surface and is banned there.
- **--rb-ink / --rb-fill** — context: `RB` text inside a read-back box (graphite on buff fill). `--ink-on-paper` is the same role alias, used only on a buff fill.
- **--attention / --surface-inset** — context: the amber `DIALOG` word in a cocked strip's inset DIALOG cell. Text use is allowed only on anthracite/inset, and it is below AA on holder.
- **--attention / --surface-strip** — context: the cocked-strip holder band as a non-text element (SC 1.4.11 3:1).
- **--handoff / --surface-bay** — context: transfer-marker arrows and names and `link`/`unlink` names in the rack gap. Text use is allowed only on anthracite, below AA on holder, and it is banned inside strips.
- **--focus-ring / --surface-bay** and **--focus-ring / --surface-strip** — context: focus indicator on both surfaces.
- **--rule-info (and --rb-rule, --rb-strike) / --surface-bay** — context: information-carrying borders whose presence is the state (readback box outline and strike, `budget-paused` box, nonzero `skipped` box, `TAPE stopped` box, error strips). These are non-text contrast (SC 1.4.11).
- **--rule-field / --surface-strip** — context: the in-strip field-grid rule between cells. It is also the colour of the box around the ATIS `expired` word on anthracite.
- **Stale swap** — context: on `stale` rows, `--surface-strip` is reassigned to anthracite, `--ink` to lamp-off, and `--rule-field` to rail, so lamp-off ink never sits on holder.
- Excluded as decorative: **--rule-deco** (rack rail rules, strip outer edge, minute rules, band slot). Design marks it never-text and decorative.

#### Focus ring tokens
- **--focus-ring:** focus indicator colour token (buff ink role, used on both anthracite and holder surfaces).
- **--focus-w:** focus indicator width token (distinct from `--rule-strong`).
- **--focus-offset:** focus indicator offset token.
- **--radius:** corner-radius token applied to the focus indicator (square corners across the system).
- Notes: the focus indicator is applied on focus-visible in the base layer (outline composition specified in design), appears instantly with no transition, and link hover/focus adds an underline. Focusable elements in v1 are the skip link, tape `<summary>` elements and the `new lines below` anchor. Session rows are not focusable.

#### Target size tokens
- No dedicated target-size tokens.
- **--line-h:** tape line / transfer marker row-height token, which sets the row height of the tape `<summary>` elements, the primary interactive targets in v1. It is relevant to SC 2.5.8 (24×24 minimum).
- **--strip-h:** strip height token, also the minimum-height token for the reserved v1.x brake `<button>`s (`I HAVE CONTROL`, `UNLINK`), which are not built in v1. It is relevant to SC 2.5.8 / SC 2.5.5 (44×44).
- **--space-xs / --space-micro:** spacing tokens around rows and between glyphs and names (spacing adjacent to targets).

#### Motion / transition tokens
- **--cock-dur:** cocked-strip offset transition duration token (the one high-impact motion, played once on entering dialog-pending; the return into line is instant). Reduced-motion override defined in design.
- **--cock-ease:** cocked-strip easing curve token.
- **--cock-offset:** cocked-strip spatial offset token (also reserved as rack end padding). Under reduced motion the offset position and amber band remain as state.
- **--fade-dur:** entrance fade duration token for newly arrived (`data-live`) tape lines and transfer markers only. Initial load renders instantly. Reduced-motion override defined in design.
- **--fade-ease:** entrance fade easing token.
- Notes: the reduced-motion override targets `--cock-dur` and `--fade-dur` by name. Design bans spinners, pulses, blinking, skeleton shimmer, looped animation, staggered entrances, hover colour transitions, parallax, spring physics, 3D, scroll-driven animation, canvas/WebGL and animation libraries. It also bans motion on `busy`, `stale`, `turn-ended`, the readback fill and the strip's return. Scroll behaviour is never smooth. The CLI has no motion at all.

#### State color tokens (error / warning / success / info)
Design uses no green/yellow/red hues. States are carried by ink, fill, rule, strike and a printed word.
- **--attention:** attention state (`dialog_pending` only). Not-color-alone supplement: the `DIALOG <kind>` word in bold weight, plus the spatial offset. In forced-colors mode the band maps to the system Highlight colour.
- **--rb-fill / --rb-ink:** success (confirmed read back). Not-color-alone supplement: `RB` text in the box plus the word `read back`.
- **--rb-strike:** error (refused send). Not-color-alone supplement: the word `unable` plus the typed reason and detail. In forced-colors mode the strike is dropped for a dashed outline, and the word remains.
- **--rb-rule:** open / unconfirmable readback (pending / warning). Not-color-alone supplement: the words `open` / `unconfirmable` (the drawings are identical, and only the word distinguishes them).
- **--rule-info:** declared states and errors (`budget-paused`, `TAPE stopped`, nonzero `skipped`, error strips, refusals). Not-color-alone supplement: the printed phraseology word.
- **--rule-field:** warning (`expired` budget window box). Not-color-alone supplement: the word `expired`.
- **--ink-dim:** info / muted / stale (coasting). Not-color-alone supplement: the words `stale`, `activity`, `harness`, `TAPE connecting`, `n/a`.
- **--handoff:** handoff role (not a status). Not-color-alone supplement: arrow glyph plus names plus `link`/`unlink` words.
- **CLI attention token (SGR amber) / CLI stale token (SGR dim) / callsign (SGR bold):** attention and stale. Not-color-alone supplement: the always-printed `DIALOG` and `stale` words. Colour is suppressed under `--json`, non-TTY, `NO_COLOR`, `TERM=dumb` and on VT failure.

#### Typography tokens (readability)
- **--font-label:** label / heading / display / callsign font family token (per-OS fallback stack defined in design, no web fonts).
- **--font-field:** monospace field / body / data / code font family token (per-OS fallback stack, no ligatures).
- **--fs-display / --fs-callsign / --fs-field / --fs-code / --fs-label:** font-size tokens for Display, Callsign (NAME cell), Body/Data field text, Code (expanded tape body, commands), and Label/Heading (captions, rack separators, `RB`).
- **--fw-regular / --fw-strong:** weight tokens (strong used for display, headings, callsign, `human`, the `DIALOG` word and `RB`).
- **--line-h:** body/data/code line-height token (expressed as a fixed length in design).
- **--lh-display / --lh-label:** display and label/heading line-height tokens (fixed lengths in design).
- **--strip-h:** strip height token, also the callsign line-height.
- **--track-display / --track-rack / --track-label / --track-callsign:** letter-spacing tokens (em-based in design). Relevant to SC 1.4.12 (user letter-spacing override threshold) and SC 1.4.8.
- **--stretch-label:** semi-condensed width token for labels.
- **--strip-cols / --strip-cols-wrapped / --strip-rows-wrapped / --tape-cols:** character-based column-track tokens. Strip rows have a fixed block size. The tape TEXT and INSTANCE cells and unwrapped names truncate with an ellipsis, with the full text in the expanded `<details>` body for tape lines. Relevant to SC 1.4.12 / SC 1.4.10 (no horizontal scroll at primary width; a two-line wrapped strip in the mid-width band).
- Notes: there is no prose max-width token. Labels and headings are uppercase-transformed, but session names are never text-transformed. Tape and data use tabular figures.

### ARIA-Relevant Component Patterns
- **Rack table (`<viola-session-row>` racks)** — ARIA role: `table` (the rack), `row` (each strip), `cell` (each field), `columnheader` (the caption row, once per rack). Key states / props: state lives in `data-*` attributes (`data-liveness`, `data-dialog`, `data-wrapped`), with no ARIA state attributes specified. Keyboard contract: rows are not focusable in v1 (no controls).
- **Tape (`<viola-event-feed>`)** — ARIA role: `log` on the panel. Key states / props: design specifies `role="log"` for the panel and separately bans making the whole tape an `aria-live` region. Keyboard contract: Tab moves through line `<summary>` elements.
- **Tape line disclosure (`<details class="tape-line">` / `<summary>`)** — ARIA role: native disclosure (summary acting as button, implicit expanded state). Key states / props: native open/closed state. The default disclosure marker is hidden with no replacement glyph. Keyboard contract: Enter / Space toggles, which reveals the full text (pre-wrapped, plain text).
- **Status announcer** — ARIA role: `status` with `aria-live="polite"`, visually hidden. Key states / props: announces only strips turning cocked, readback refusals and `TAPE stopped`. Keyboard contract: n/a.
- **Readback box (`<viola-readback>`)** — ARIA role: none specified. The square `.rb` is `aria-hidden="true"`. Key states / props: `data-rb` = open | read | refused | unconfirmable. The accessible name comes from the word cell, so the line reads e.g. "send to builder, read back". Keyboard contract: not focusable.
- **Transfer marker (`<viola-transfer>`)** — ARIA role: none specified (a text line with arrow glyphs and names, in the rack flow under the strip). Key states / props: `data-live` for the fade only. Keyboard contract: not focusable.
- **Skip link** — ARIA role: link. Key states / props: visible on focus, labelled `skip to tape`, and the first tab stop. Keyboard contract: Enter.
- **`N new lines below` anchor** — ARIA role: link (link-styled, targets the tape end). Keyboard contract: Enter, and the jump is instant.
- **Links (general)** — ARIA role: link. Key states / props: inherit colour, underline on hover/focus only. Keyboard contract: Enter.
- **ATIS header (`<viola-atis>`)** — ARIA role: none specified (sticky header of text cells). Key states / props: none. Keyboard contract: not focusable.
- **Reserved v1.x brake buttons (not built in v1)** — ARIA role: native `button` (`I HAVE CONTROL`, `UNLINK`). Key states / props: no pressed fill. Confirmation comes via the resulting tape line and strip value, and no `aria-pressed` is specified. Keyboard contract: Enter / Space, with the standard focus ring. The confirmation surface is reserved (modal-like, not in v1).
- **Not present in v1:** dialogs/modals, tabs, menus, combobox, accordions beyond native `<details>`, form inputs or credential fields, tooltips, popovers, toasts, command palette and keyboard shortcuts.
