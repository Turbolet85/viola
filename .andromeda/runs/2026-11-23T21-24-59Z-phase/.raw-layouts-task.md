Adds tests for the hypr recorder's three untested `record-move` failure codes and lands the 5 s compositor read bound `HYPRCTL_DEADLINE` as a time-bound row of its own.
Re-measures at HEAD the seam counts the earlier split-carry notes carried, and stops before R2, the one live open, which gates v2-07.

@task_item n=1 part=needs

@task_item n=2 part=needs
Usage refusals of open: exit 2 as clap's usage error, plus one fixed line for a word after `--` other than `claude`, standing beside the existing launch-pair-after-the-dashes usage line of run and revive.
@task_item n=3 part=needs
The terminal start: `foot` found on PATH and started directly with no shell, argv `foot --app-id=viola.<name> --title=<name> --working-directory=<cwd> <pinned viola> --home <home> run <name> …`; no shell line built from any argument; exit 1 `terminal-not-found` when foot is absent.
@task_item n=4 part=needs
Placement: poll the compositor's clients at 100 ms for up to 5 s until a window's pid is the terminal's, then issue the one closed move dispatch to the parent's workspace or --workspace N, no focus change; no parent window or no window seen means no move, recorded `unplaced`; off Hyprland (the seam's unsupported / unreachable, no environment read) the terminal still starts and the record says why; a locked desktop does not stop the open.
@task_item n=5 part=needs
Liveness: open returns once the instance's endpoint is live, waiting at most 30 s, else exit 1 `not-live` with the window left standing; each new bound (30 s, 5 s, 100 ms) is a time-bound row of its own.
