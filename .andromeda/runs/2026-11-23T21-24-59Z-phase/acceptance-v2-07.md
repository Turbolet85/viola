From the CLI and from an agent's own shell, an open brings up a new terminal window running the named wrapped session, placed beside its parent's window on Hyprland and left to the window manager elsewhere; it returns only once the session is live, records the window's identity and the open's origin, and names the calling agent as the parent when none is given. Over the fakes (tests/cli_open.rs): the closed foot argv, live within the bound, the `window {address, workspace, placement, origin}` record in the snapshot and its one line after `launch`, `placed` by the one move, `unplaced` · `window-unseen` · `unsupported` where it cannot place, the caller named as the parent with origin `agent`. Gated on R2 alone, for the real window placed beside its parent's on Hyprland: `evidence/r2.md` holds the line `r2: green placement=placed …` (the recorded address standing in `clients` with the foot's pid, its workspace the parent window's); a stand-in never verifies it.
