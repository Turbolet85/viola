## Relevance
relevant — the chunk creates the cli surface's board (`viola list`, human and `--json`); it builds the uncoloured form only, so the styled TTY form and the unwrapped rack of the same sections stay unbuilt.

## Constraints
- Surface and region: the board is the cli surface's one whole-bay screen. Its hierarchy, top to bottom, is the one static context header, the caption row, then one strip row per session; the wrapped rack has no separator line of its own (per layout-templates §Surface: cli / Primary screens (commands) and §Surface: cli / Component — Primary content block 1: `viola list` strip rows, Rack separator bullet).
- The BAY line is the only header on any verb and its cell order is fixed, cells apart by the two-space gutter, with no rule line under it. The section requires every cell of that order, the window cells' passed-window word and the read-age cell included, not only the gate and skipped cells the scope names; whether the slice's `budget` reading carries what the passed-window word needs is research's question (per layout-templates §Surface: cli / Component — Header / banner (the BAY context line)).
- The cli section words no BAY form for a missing reading (the scope's `budget: "unknown"`), no age units beyond its one sample, and no named order for the three skipped counts beyond the `--json` sample's key order. The web header it is derived from prints a fixed word in each cell on a first reading. Whether that word carries to the cli line is not worded: a P4 fork, never an implementation choice (per layout-templates §Surface: cli / Component — Header / banner (the BAY context line); the web form is §Surface: web-spa / Wireframe — Bay, first reading / empty).
- Six columns in the fixed caption order, each padded to its widest word, the two-space gutter between them, no box-drawing border; inside one field the ASCII separator replaces the web's dot. The section names the widest word of five columns and gives no width rule for NAME beyond "wrapped names are never clipped" and "no line ever wraps"; how the NAME column is sized for the longest name present is research's to close (per layout-templates §Surface: cli / Component — Primary content block 1: `viola list` strip rows, Columns and Truncation bullets).
- Rows are ordered by name and nothing is re-sorted by state; the web rack states the same order as `ViolaName` ascending and binds it to this verb (per layout-templates §Surface: cli / Output structure — `viola list` (human TTY); the web side is §Surface: web-spa / Component — Primary content block 1: racks of `<viola-session-row>` strips, Ordering bullet).
- The uncoloured form is the styled form's characters with no SGR, and nothing is truncated when the width is unknown. This supports the slice's "same characters on every stream" as lossless in words. It does not discharge the TTY section: that section requires bold NAME values, the accent on the `DIALOG` word and a dim stale row on a human terminal, and the slice leaves those three unmet (per layout-templates §Surface: cli / Output structure — `viola list` (piped / `NO_COLOR` / `TERM=dumb`) and §Surface: cli / Output structure — `viola list` (human TTY)).
- `--json` is one document on stdout with no header line, no colour and no glyph; layouts owns no field list for it, only that its three shapes equal the GUI route's (per layout-templates §Surface: cli / Output structure — `viola list --json`).

## Patterns to follow
- Expression level 0.0 on a non-TTY stream and under `--json`: no colour, no non-ASCII glyph, no cursor control; fixed-column static rows appended once, never redrawn (per layout-templates §Surface: cli, Expression level paragraph).
- The empty board is one line that names the verb that fills it. The cli section gives that line alone and does not say whether the BAY line and the caption row print above it; the web rack requires its captions drawn even when empty. Which the cli does is unworded: research reads the other masters, else a P4 fork (per layout-templates §Surface: cli / Output structure — `viola list` (human TTY), Empty board bullet; the web rule is §Surface: web-spa / Component — Primary content block 1: racks of `<viola-session-row>` strips, Caption row bullet).
- A cell is never blank: the web strip prints one fixed word for a missing reading and another for a field absent by contract, and the cli columns are declared identical to the web strip's fields and words. The cli samples show the absent-by-contract word only on unwrapped rows. So a wrapped row whose CLI version or status is missing takes the missing-reading word by that parity clause; the cli section does not say so itself (per layout-templates §Surface: cli / Component — Primary content block 1: `viola list` strip rows, Columns bullet; the web rule is §Surface: web-spa / Component — Primary content block 1: racks of `<viola-session-row>` strips, Strip anatomy).
- Row-mode escaping: the section scopes the stricter escaper (C0 and C1 as hex text, LF and TAB included, so a row never splits) to fields that come from `claude agents --json`. This slice shows no such field. Applying it to the CLI version text is the scope's inference: the plan neither requires nor forbids it for a snapshot field, so the plan step states it as the slice's own rule and the wrap may owe the bullet an amendment (per layout-templates §Surface: cli / Component — Primary content block 1: `viola list` strip rows, Escaping bullet).
- Streams and failure lines: results on stdout; refusals, hints and errors on stderr, never mixed; the hint is the last stderr line; no terminator word. The section's list of cli verbs that print the one internal-error line does not name `list`, and the cli surface words no refusal line for `list` at all (a missing home, a home or an instance that fails its check). The nearest worded forms are `revive`'s state-files pair and the web's state-unreadable strip. What `list` prints there is research's question against the other masters (per layout-templates §Surface: cli / Component — Primary content block 2: refusal lines and the `unable` column, Line form and Streams bullets; §Surface: cli / Component — Footer / terminator).

## Anti-patterns to avoid
- No seventh column and no link shown: the six columns are a contract LLM drivers read, a new field goes into `--json` first, and a human column added is a design change (per layout-templates §Surface: cli / IA notes, Output as a contract bullet, and §Surface: cli / Component — Primary content block 1: `viola list` strip rows, No link column bullet).
- No banner, version line, logo, rule line, box drawing, pager, interactive prompt, summary or `done` word around the board (per layout-templates §Surface: cli / Component — Header / banner (the BAY context line), No banner bullet; §Surface: cli / Component — Primary navigation (verb structure); §Surface: cli / Component — Footer / terminator).
- No clipping of a wrapped name, no wrapped line, no reordering by liveness, dialog or wheel state (per layout-templates §Surface: cli / Component — Primary content block 1: `viola list` strip rows, Truncation bullet).
