@task_prose part=chunk
Builds one standing, committed live rig that later live rounds reuse in place of per-round evidence scripts: it starts the real claude CLI, or viola wrapping it, in a pty it owns, keeps a terminal screen model and the screens it reads as evidence, and reads the CLI's trust and modal dialogs by their drawn literals and selector rows.
The rig owns its isolation from the founder's real config and login (scratch root, private config dir, guarded credentials copy, token-window read) and its process hygiene (ends what it starts on every exit path), each proven once on the fake agent.
It re-measures what each earlier round's evidence scripts built, got wrong and must not rebuild, and carries live readings: submit-time whitespace trim, the hook-latency window before a send's paste, a fired scheduled wake's payload source and its turn-ended count, and the live record home of viola verify --record.
The product binary gains no verb and no surface; no product behaviour changes beyond what a carried reading forces and the founder places.
P3 ends with one sizing block before P4: the rig's steps and files, whether rig plus readings fit, a split if not, and each live start by shape, count and typed keys.
@task_item n=1 part=needs
The CLI's verb set, viola --help verb groups and per-verb usage stay as they are: the rig is a test-only harness and adds no verb, flag or output to the product.
@task_item n=2 part=needs
Where the rig starts viola wrapping claude, it does so through viola run <name> -- claude under a private home passed with the --home global flag; the run start's passed output and its start refusals (home tree refused, socket directory refused, already live) are what the rig reads back, not new shapes.
@task_item n=3 part=needs
A live viola verify --record takes its record home from a helper like the tests' record home, holding no path component named home; the verify output's --record line, summary and refusals (viola home not private, claude CLI not found, CLI version unreadable) are read as they stand.
@task_item n=4 part=needs
Live reading of which whitespace the CLI trims at submit on the input box (leading, trailing, inside a paste): viola send's delivery confirmation and read back keep their trailing-only tolerance (ASCII space, TAB, CR, LF) until the reading lands; the send text refusals and the readback mirror do not change from this chunk.
@task_item n=5 part=needs
Live measurement of the hook-latency window: a turn the CLI starts whose prompt-submit has not reached the wrapper before a send's paste; the send outcome words (unable, unconfirmable) and the read back are observed, not reworded.
@task_item n=6 part=needs
Live reading of a fired scheduled wake: whether its prompt-submit payload carries the optional source field, captured as closed words, and that turn-ended's scheduled_wakes reads 1 for a real wake (one start, two sends, wrapper stopped before the wake is due); viola wait's turn-ended output and its --json document are read, not changed.
@task_item n=7 part=needs
The rig reads the claude CLI's trust dialog and modal dialogs by their drawn literals and selector rows; the fake agent's modal fidelity and DEL fidelity follow that reading; viola's own DIALOG word, viola wait's dialog lines and viola answer's output are what a dialog surfaces as and stay as ratified.
@task_item n=8 part=needs
Nothing of the host's paths, the founder's status line or his config reaches any record the rig keeps; the token-window value is never counted into a record.
@task_item n=9 part=needs
A start is refused under 20 minutes of token left, read from the token window; the credentials copy is removed on every exit path; no write to the founder's real config file is left unexplained.
@task_item n=10 part=needs
Each isolation property is proven once by a named check on the fake agent, with no live start; every step that needs no live start is planned on the fake agent.
@task_item n=11 part=needs
Process hygiene: the rig and any booted test it stands for end what they start on every exit path, the rig's own kill deadline included, proven by a census of processes under the rig's scratch root at exit or a stronger means.
@task_item n=12 part=needs
Where the rig reads viola's own output it reads the ratified forms: human output as the contract, --json as one document, results on stdout and the rest on stderr; it parses no line a contract does not fix.
@task_item n=13 part=needs
Test bounds: a test waiting on a channel or thread takes a bound; a test socket lives under the short /tmp root; a stamped home comes from the shared stamp's copy; no mutation run in this chunk.
@task_item n=14 part=needs
The live cap and the typed keys of each live start are the founder's, per chunk; the sizing block names each live start by its shape, count and typed keys, and the split placement is the founder's.
