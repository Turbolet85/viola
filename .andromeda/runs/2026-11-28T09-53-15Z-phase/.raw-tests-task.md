@task_prose part=chunk
Builds the view of the fleet console: the frame `viola console` draws past the scaffold's one fixed frame.
It shows the home's instances as lineage trees, with each session's state, wheel holder and last activity in the board's words.
Every drawn row is control-escaped, and the six board captions are reused with their words and slot order.
The frame re-reads the fleet so a disk change shows without a key, and it stays whole at a quarter-screen tile's size.
It adds no action, key, send or selection, and opens no window on the operator's desktop.

@task_item n=1 part=needs
Lineage trees: the console draws a home's instances as parent/child trees in the order and indentation of the board's lineage ordering for `viola list`. It reuses that ordering and builds no second tree.
@task_item n=2 part=needs
Session state in the board's words: each session's state (working, idle, waiting on a dialog, stalled, with no budget state) and its liveness (live, stale, gone, so that an exit shows) come from the same board read model `viola list` uses. No new vocabulary.
@task_item n=3 part=needs
Wheel holder and last activity: each session's wheel holder and last activity are drawn in the board's words and the board's timestamp form.
@task_item n=4 part=needs
Six board captions: the console reuses the board's six captions with their words and slot order, the shared fixed captions of the list board.
@task_item n=5 part=needs
Control escaping of every drawn row: names, cwd and any captured text pass the existing human-output control escaping, which shows a control character as hex. No raw C0, C1 or DEL byte reaches the screen.
@task_item n=6 part=needs
Kept current: the frame re-reads the fleet so that a new instance, a state change, a wheel move or an exit shows without a key. The mechanism and its cost are measured on fleets of 1, 8 and 33 test-owned instances.
@task_item n=7 part=needs
Whole at quarter-screen: at the size a quarter-screen tile gives, the frame stays whole, with nothing cut mid-row and no wrap. The chunk also defines what the frame does with a fleet or a row that does not fit.
@task_item n=8 part=needs
The frame writer stays as the scaffold built it: each draw redraws the whole frame from a cleared top-left, in plain ASCII with no SGR, through the one writer, with no cell grid and no diffing. The size is polled every 100 ms and re-read on each key. A changed size redraws the frame whole, and a key after a resize waits for the new size.
@task_item n=9 part=needs
The console role file and its two events, console-frame and console-key, plus any new state-read event the keystroke driver needs so it reads state, never the screen. A new event joins every list and schema that pins an event, and its log line keeps the process log line format.
@task_item n=10 part=needs

@task_item n=11 part=needs

@task_item n=12 part=needs

@task_item n=14 part=needs
