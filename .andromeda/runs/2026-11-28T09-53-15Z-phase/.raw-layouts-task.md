@task_prose part=chunk
Builds the view of the terminal fleet console: the frame `viola console` draws, past the scaffold's one fixed frame.
It shows the home's instances as lineage trees, each session's state, wheel holder and last activity in the board's words, every drawn string control-escaped.
The frame re-reads the fleet so a change on disk shows without a key, and stays whole at the size a quarter-screen tile gives.
It reuses the six board captions with their words and slot order, and adds no action, key, send or selection.
@task_file n=1 path=src/human/console.rs mark=edits
what: the console's one frame writer, the component that draws the whole fleet console frame — edits: the frame it draws (its rows, captions and their escaping, and what it does with a fleet or a row that does not fit)
@task_file n=2 path=src/cmd/console.rs mark=edits
what: the `viola console` verb's loop, holding the 100 ms size poll and the key read — edits: the loop's re-read of the fleet that keeps the frame current
@task_item n=1 part=needs
The console surface: the fleet console as its own surface, with its frame floor of 80x24, which the view's frame must still hold.
@task_item n=2 part=needs

@task_item n=3 part=needs

@task_item n=4 part=needs
Each session's state shown with the words `viola list` uses for it (working, idle, waiting on a dialog, stalled), read from the same board read model, with no budget state and no new vocabulary; words carry every state, and the board's words for unknown or stale readings (a WHEEL unknown, a DIALOG unknown, a failed agents read, a stale row) are the ones it shows.
@task_item n=5 part=needs

@task_item n=6 part=needs

@task_item n=7 part=needs
The six shared board captions reused with their words and slot order (the fixed shared captions, carried to the fleet console); where they stand in the code is found at P3.
@task_item n=8 part=needs
Control escaping: every upstream- or disk-sourced string the view draws (names, cwd, any captured text) passes the existing control escaping the board rows use before it reaches the terminal; no raw C0, C1 or DEL byte reaches the screen.
@task_item n=9 part=needs
Kept current: the frame re-reads the fleet so a new instance, a state change, a wheel move or an exit shows without a key; the mechanism and its cost are measured at P3 on fleets of 1, 8 and 33 test-owned instances.
@task_item n=10 part=needs
Whole at quarter-screen: nothing cut mid-row and no wrap at a quarter-screen tile's size, and a stated handling of a fleet or a row that does not fit the frame, bound by the board's rules for name truncation (only unwrapped names truncated, a ViolaName never case-transformed), column widths and an unknown terminal width.
@task_item n=11 part=needs
The hand-written frame writer it builds on: each draw redraws the whole frame from a cleared top-left in plain ASCII with no SGR, through the one writer, with no cell grid and no diffing; the size polled every 100 ms and re-read on each key, a changed size redrawing whole, no SIGWINCH handler; the view's width and truncation logic is new.
@task_item n=12 part=needs
