@task_prose part=chunk
Builds the fleet view of `viola console`, past the scaffold's one fixed frame: the home's instances drawn as lineage trees in the board's own lineage ordering, each session's state, wheel holder and last activity in the board's words, with the six board captions reused in their words and slot order.
Every upstream- or disk-sourced string the view draws (names, cwd, any captured text) passes the existing control escaping, so no raw C0/C1/DEL byte reaches the terminal.
The frame re-reads the fleet so a change on disk (a new instance, a state change, a wheel move, an exit) shows without a key; the mechanism and its cost are measured on fleets of 1, 8 and 33 test-owned instances.
The frame stays whole at a quarter-screen tile size (no row cut, no wrap) and handles a fleet or row that does not fit; no action, no new key, nothing dispatched to the compositor.

@task_item n=1 part=needs
The console view adds a human terminal output that draws upstream- and disk-sourced strings (instance names, recorded cwd, captured text): the human-output control escaping applies to each before any byte reaches the terminal, checked on decoded characters, and any fit-to-width cut happens without letting a raw control byte through.
@task_item n=2 part=needs

@task_item n=3 part=needs
The view reads the fleet through the board read model: the board's rule holding the home to the read rule and the strict-modes check before trusted state is read, and its whole-board refusal, bind the view's every re-read, not only the first.
