- 2026-10-09: A build's file hash is not a proof that two builds load the same code: the release file's hash moved with comment text alone, and an earlier build's bytes were not reproduced from the same source text. When a live reading was taken on an earlier build of the final tree, read each loaded section (`.text`, `.rodata`, `.data`, `.data.rel.ro`, `.eh_frame`, `.gcc_except_table`) from both files with `objcopy -O binary --only-section=<name>`, hash each, and record the pairs with the time; take two controls through the same script (a file against itself, a file against another program). Record a file-hash difference as not explained unless its cause was measured, and keep the earlier build's copy until the reading is taken (a live home on the tmpfs is gone at a reboot).
