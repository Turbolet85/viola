## Analysis

**Cross-reference pass (every mismatch noted before patching)**
- Harness commands: `viola-harness gate` (§9 Quality gates row) and `supervise` (§3 boot step 5) have no body, flags, output JSON or exit codes in §3.
- JUnit file: nextest always writes `target/nextest/ci/junit.xml`, and every nextest invocation (unit, integration, e2e) overwrites it. Nothing produces the `junit-*.xml` files that `gate` reads.
- Boot model: §3 `run` step 2 says tests self-boot through rstest. Paths 2 and 7 call `agent-run boot`, and Paths 3, 4, 6 and E3/E4 clean up with "harness `cleanup`". So the plan uses two models, and neither the session-id collision question nor the nested-`cargo run` question is answered.
- Double counting: `contract_` is not excluded from the integration filterset but is included in the E2E one, so the contract suite runs twice.
- Status document: the prose says `list` and `api` members, but the JSON block has `list` and `ui`. `last_error` is open-ended ("e.g."). The `suites[].suite` enum has no value for `--fuzz-replay`.
- Log ownership: §3 Log format says the test plan owns the fields. `log-format-bind-with-obs` says to consume the obs-plan schema verbatim, and the closing Bootstrap paragraph says both shapes "come from obs-plan §3". These contradict each other.
- Tool installs: §9 installs only 4 tools, with no versions. hyperfine, cargo-modules, zizmor, cargo-fuzz and jq/jaq have no install mechanism and no Bootstrap slot. cargo-deny and zizmor say "may alternatively" use the actions, so each has two possible version sources.
- Time seams: Path 6 step 7 calls mock_instant in the test process to control a separately spawned `viola run`. That cannot work.
- Unit-boundary claims: E2 and §12 say Windows handle non-inheritance is asserted "at the product unit boundary", but §4 viola-channel has no such case.
- §11 vs §12: the CI caching and parallelism bans contradict the §12 browser-cache decision (dimension 7, deferred).

**1. Downstream Readiness.** Four defects confirmed from the anchor and the secondary evidence: missing gate/supervise, the JUnit rename, two boot models, and the obs ownership contradiction. **2. Tool Anchoring.** The Path 6 cross-process mock_instant claim is confirmed (catalog: global mode is in-process only). **5. Performance Budget Coverage.** Gaps confirmed: p99 column semantics, no warm-up rule, no non-instrumented perf build, the 16 s real-time smoke, and missing send/wait latency rows. Deferred because the patch budget went to dimensions 1–3. Patch 1 does make a missing perf JSON a breach.

**7. Anti-Pattern Relevance.** The contradictory §11 CI bans (caching, sequential runs) and the missing viola-specific bans are confirmed. Deferred.

**8. E2E Selector Strategy.** `cell` role and the row × columnheader rule are missing. Deferred (signal-diluting, over budget).
