## Patches

### Patch 1: Give `--fuzz-replay` a committed corpus, an empty-corpus failure and a suite counting rule
**Reason:** Dimension 1 (Downstream Readiness), with a Dimension 4 green-CI hole. `gate --require fuzz-replay` has no way to count the suite. With no committed corpus, the PR `-runs=0` replay runs on an empty corpus and passes vacuously, and nightly crash reproducers are thrown away with the ephemeral runner (§9 Fuzz replay cache: none).
**Old:**
```
- `--fuzz-replay` runs `cargo +nightly fuzz run <target> -- -runs=0` for each target, on ubuntu only.
```
**New:**
```
- `--fuzz-replay` runs `cargo +nightly fuzz run <target> -- -runs=0` for each target, on ubuntu only. The replay corpus is the committed `fuzz/corpus/<target>/`. Each target's corpus is seeded with the §7 recorded payloads its parser accepts, and every reproducer from `fuzz/artifacts/<target>/` is committed there together with its fix. Nothing is cached or carried over between CI runs. A missing or empty corpus dir fails that target with `reason:"corpus-empty"`, never a vacuous pass. Suite `fuzz-replay` has one entry per target: `passed` counts targets that exit 0 over a non-empty corpus, `failed` counts the rest, and `failures[]` names each failing target. The `nightly.yml` time-boxed run uploads `fuzz/artifacts/` as an artifact and fails the job on any crash.
```

### Patch 2: State when `boot`'s default instances and `--ui` apply
**Reason:** Dimension 1 (Downstream Readiness). Path 2, Path 7 and the Playwright boots pass `--ui` explicitly with `--instance`. Path 6 step 1 relies on the defaults with only `--statusline-echo`. `--perf` boots `--unstamped builder` with no UI. The contract never says whether `--instance` replaces the default list or whether `--ui` stays implied, so setup-project cannot implement the `boot` flag parsing.
**Old:**
```
The default is instances `overseer` and `builder` plus `--ui`, with `--agents-mode recorded`.
```
**New:**
```
With no `--instance` flag, the instances are `overseer` and `builder` and `--ui` is implied, whatever other flags are given (for example Path 6's `--statusline-echo`). One or more `--instance` flags replace that default list, and the UI is then started only if `--ui` is given (Paths 2 and 7, E4, the Playwright session fixture; `--perf` boots without it). `--agents-mode` defaults to `recorded`.
```
