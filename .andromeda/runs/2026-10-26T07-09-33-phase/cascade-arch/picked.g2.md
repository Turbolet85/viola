### established-decisions#22.1 · values · dec-cli-conventions · ## Established Decisions · lines 211–211
- **[CLI Conventions] Human text by default, `--json` for agents, a typed exit code per refusal. Prompt text comes from stdin or `--file`, never from a leading-slash argument.** viola warns when an argument carries a Git Bash rewritten-path prefix. Rationale: Git Bash rewrites `/skill` arguments into Windows paths (brief §6), and agents need machine-parseable refusals. `viola revive` takes `--json` on both arms (chunk 2026-10-17-cli-machine-contract): a refused strict-modes check or a preflight refusal prints `{"v":1,"error":"<code>","detail":null}` (`strict-modes-failed` · `already-live` · `no-session` · `session-live` · `cwd-missing`) in place of its `unable:` / `hint:` pair, exit 1, and `<name> --list --json` prints `{"v":1,"ok":{"sessions":[…]}}` in log order; without `--json` the pairs and the `--list` rows are byte-identical. A refusal `run`'s start makes after a passed preflight (`batch-script-child`, `pinned-hash-mismatch`, `squatted-name`, a `claude` not on `PATH` as `internal-error`) prints no document as landed; its document is owed to the working-route entry "Exit-cause code catalogue".
