# a11y extract

## Relevance
partial — the chunk builds the `run --browser` → `playwright` suite pipe that every web-spa a11y check later rides on. It adds no UI surface and makes no WCAG assertions: axe, the a11y fixture, the rows and the a11y gate are Epoch 8, per the scope's Boundaries.

## Constraints
- **The pipe's shape is the a11y harness's shape.** a11y-plan §3 CI integration and §9 Pipeline integration require that a11y specs run as ordinary files in `e2e-web/`, inside the existing `playwright` suite. The path is `scripts/agent-run.* run --browser` → `npx --prefix e2e-web playwright test` → `gate --require playwright`. That means no separate driver, no `npm test:a11y` and no new `suite` enum value. The pipe this chunk lands must be the one the Epoch 8 a11y specs join unchanged.
- **OS-leg conflict (for P3/P4).** a11y-plan §3 CI integration, §9 Pipeline integration, §11 CI ("NEVER … run `--browser` on Windows or macOS legs") and D-A11Y-12 all require `--browser` to be ubuntu-only, exiting 2 with `browser-linux-only` elsewhere. Founder ruling W125 ("Playwright on three CI OSes") contradicts every one of these clauses, not only test-plan §3. The a11y-plan needs the same wrap amendment as test-plan.
  - A possible split for P4 to weigh: the pipe runs on three OSes, while the web a11y verdict stays ubuntu-bound. Two a11y-plan clauses anchor that: §6 Contrast verification harness (axe `color-contrast` is calibrated to the ubuntu DejaVu font fallback), and §9 CI-specific resource attributes (rows carry `os:"linux"`).
- **A missing Chromium is a failure, never a skip.** a11y-plan §9 Pipeline integration and §11 CI require this. It applies on every leg this chunk wires, WSL pre-push included.
- **Zero-flake discipline.** a11y-plan §10 (the always-required invariant and the cross-input parallel) and §11 SLO require `retries: 0` in the Playwright config. They also ban retry-once policies, `test.skip` / `test.fixme` / quarantine tags, and sleeps or `waitForTimeout`.
- **One browser stack.** a11y-plan §11 Strategy and D-A11Y-05 require that headless Chromium under Playwright Test 1.63.0 be the only automation client: no Puppeteer, Lighthouse or pa11y beside it.
- **Config choices the a11y specs inherit.** a11y-plan §3 A11y testing tool pick → Configuration and §11 CI ban `bypassCSP` and an axe `locale`. The shared `playwright.config.ts` must not set `bypassCSP` (or an equivalent global `use` option) that later a11y specs would inherit.
- **Bootstrap assumption made false.** a11y-plan §3 Bootstrap phases → a11y-tooling-install assumes that `@axe-core/playwright@4.13.0` is "already declared in `e2e-web/package.json` by tests". The scope defers that pin to Epoch 8, so after this chunk the assumption no longer holds. The Epoch 8 a11y entry must declare the pin itself, or the plan clause needs a wrap amendment. The chunk should record this as a route note.

## Patterns to follow
- **`e2e-web/` layout.** Later a11y chunks write into this tree, so the stub must not claim these paths:
  - `tests/*.spec.ts`: the future `bay-steady-state.spec.ts` lives here (§3 Contrast verification harness);
  - `fixtures/a11y.ts`;
  - `schemas/a11y-row.v1.json`;
  - `a11y/sc-coverage.json`;
  - `test-results/a11y/` and `test-results/lint/`;
  - `.htmlvalidate.json` and `eslint.config.js`.

  (All per a11y-plan §3 Bootstrap phases and §3 Structured violation JSON schema.) `testDir` and `outputDir` should resolve to `e2e-web/tests` and `e2e-web/test-results`.
- **Suite artifact.** The Playwright JSON report (+ JUnit) is the suite `artifact` that the harness `run` JSON points at. Its `attachments[]` later carry the scrubbed a11y evidence (per a11y-plan §3 CI integration → Artifact; §9 E2E row). The `pw.json` reporter path this chunk sets is that artifact.
- **Artifact upload.** `e2e-web/test-results/` is uploaded by `actions/upload-artifact` v7.0.1, SHA-pinned, `if: always()` (a11y-plan §9 Artifact retention). The plan assigns this to the later a11y-ci-gate-wire phase "if `ci.yml` lacks it". Whether this chunk adds the upload now, with the same pin and condition, is P4's call.
- **Exact pins.** devDependencies are pinned exactly through the committed npm lockfile (a11y-plan §3 Bootstrap phases → a11y-tooling-install). The lockfile shape set here is the one later a11y devDeps join.

## Anti-patterns to avoid
- Never add a `webServer`, a new `suite` value (such as `a11y`) or a separate `npm test:a11y` driver outside `scripts/agent-run.* run --browser` (a11y-plan §11 CI). This matches the scope's note that the stub page must not pre-empt the `boot`-starts-`viola ui` shape.
- Never give the stub spec an `@a11y` or `@sc-*` tag, and never present its trivially true assertion as a11y evidence. An SC tag on it would falsely credit `sc-coverage-report.json` later (a11y-plan §9 Aggregation row; §11 Universal "NEVER claim WCAG conformance without machine-verifiable evidence").
- Never treat `browser-missing` as a skip (a11y-plan §11 CI).

## Contract bindings
- **a11y ↔ tests harness.** a11y rides the tests-owned `run --browser` step and the `playwright` suite in `run-summary.json` / `gate --require playwright` (a11y-plan §3 CI integration; §9 E2E row). The OS-leg amendment to test-plan §3 must be mirrored in a11y-plan §3, §9, §11 CI and D-A11Y-12.
- **a11y ↔ security.** Later a11y artifacts are scrubbed of the token, `?t=`, absolute paths and `CLAUDE*` before any attach (a11y-plan §3 Structured violation JSON schema → Scrubbing). For this chunk the binding is only that the pipe's artifacts (`pw.json`, `pw-junit.xml`) must not carry host absolute paths into uploaded CI artifacts. Whether Playwright's JSON reporter embeds absolute spec paths is research's question.
- **a11y ↔ CI.** The ubuntu-leg lint stage and the `if: always()` aggregation step are later a11y-ci-gate-wire additions to the same `ci.yml` job this chunk creates (a11y-plan §9 Lint and Aggregation rows).

## Acceptance criteria contributions
- (a11y) The stub runs only through `scripts/agent-run.* run --browser` → `npx --prefix e2e-web playwright test`. `gate --require playwright` passes, `playwright.config.ts` holds no `webServer`, `e2e-web/package.json` has no a11y-specific test script, and no new `suite` value appears in `run-summary.json` (per a11y-plan §9 Pipeline integration; §11 CI).
- (a11y) `playwright.config.ts` sets `retries: 0` and sets no `bypassCSP`. The stub spec uses no `test.skip` / `test.fixme` / `waitForTimeout` (per a11y-plan §10 Always-required SLO invariant; §11 SLO; §3 A11y testing tool pick → Configuration).
- (a11y) With Chromium absent, `run --browser` reports `browser-missing` as a failure, and `gate --require playwright` does not pass it as skipped (per a11y-plan §9 Pipeline integration).
- (a11y) The stub spec's title carries no `@a11y` / `@sc-*` tag (per a11y-plan §9 Aggregation row; §11 Universal).
