# design extract

## Relevance
partial — the chunk renders no web surface and adds no token; its design surface is the human CLI output of three verbs (`viola send`'s `budget-paused` refusal and hint, `viola release --budget`'s result line, `viola revive`'s strict-modes refusal) plus the snapshot and `budget-gate` values later surfaces print.

## Constraints
- design-system §Surface: cli → Component Patterns 2 (`viola send`: the readback mirror) requires a refused send to print the `[/ ]` mirror, the word `unable` padded to the readback-word column, the instance name, then reason and detail as separate two-space-separated fields, followed by exactly one `hint:` line keyed by the reason; the `budget-paused` hint text is fixed there. Whether the landed `send` refusal printer already renders `budget-paused` in that form (the reason has had no producer until now) is research's question.
- design-system §Surface: cli → Component Patterns 2 (`viola send`: the readback mirror) requires that no hint reaching a driver names `viola release` (T3), and that a hint never quotes the sent text or any upstream text; the `budget-paused` hint is one of the two it names as driver-reaching.
- design-system §Surface: cli → Exit-code phraseology requires exit 11 to print `unable  budget-paused` with the detail word `five-hour` or `seven-day` on stderr, and a refusal object under `--json`; no other detail word is admitted for this reason.
- design-system §Color Palette → Domain status colors (rows `BudgetWindow::five-hour`, `BudgetWindow::seven-day`, `RefusalDetail::five-hour`, `RefusalDetail::seven-day`) fixes the two window vocabularies: the label form `5H` / `7D` for readings and the detail words `five-hour` / `seven-day` for refusals. The refusal, the `budget-gate` `window` value and any human line of this chunk use the detail words, never the labels and never a third spelling.
- design-system §Surface: cli → Component Patterns 4 (Wheel, link and gate verbs) requires `viola release <name> --budget` to print one line: the instance name, the gate-lifted phrase with the override's end as a UTC clock time (`HH:MM:SS` + `Z`, as its sample), and the wheel holder as it stands. The section carries one sample only: it states no line for a `release --budget` when no pause stands, nor for a crossed window whose `resets_at` is `unknown` — a gap for P3/P4, not a design ruling.
- design-system §Surface: cli → Tokens (Colour decision order; Streams) requires results on stdout and refusals with their `hint:` lines on stderr, no hint line under `--json` (one JSON document on stdout with the typed exit), and limits SGR to the amber `DIALOG` word, dim `stale` rows and the bold NAME column: none of this chunk's lines is styled in any mode.
- design-system §Surface: cli → Component Patterns 2 (the `viola revive` exit-1 refusals) requires the strict-modes refusal to be the first read in its fixed order, printed as one fixed-message `unable: …` line and its one hint, showing no recorded directory, pid or logged id. Whether the reordered check on `revive`'s start arm still reaches that printer with no log open is research's question.

## Patterns to follow
- The typed-refusal line shared by every `send` refusal (`[/ ]` mirror · `unable` · name · reason · detail, then `hint:`): `budget-paused` reuses the path `human-typing` prints through, per design-system §Surface: cli → Component Patterns 2 (`viola send`: the readback mirror).
- The gate-verb result line (name first, two-space fields, fixed phraseology words, a UTC clock time ending in `Z`), per design-system §Surface: cli → Component Patterns 4 (Wheel, link and gate verbs).
- The fixed-message start refusal (`unable: <text>` then one `hint:` per cause, exit 1) that `viola run` and `viola revive` share, per design-system §Surface: cli → Tokens (Streams) and §Surface: cli → Component Patterns 5 (`revive`).
- ASCII-only human output with two spaces between fields and ` - ` in place of `·` inside one field (the board's later `driver - budget-paused` cell follows it), per design-system §Iconography (Separator).
- A missing reading is the printed word `unknown`, never a blank, a zero or a blocked state, and old information carries its age, per design-system §Brand Identity (Domain anchors: Fuel state / minimum fuel; ATIS information with its age).

## Anti-patterns to avoid
- No colour, glyph or status mark on a budget line: `budget-paused` is a phraseology word, never amber, red or a `✗` prefix, per design-system §Anti-Patterns → Per-Surface Bans (cli) and §Anti-Patterns → Rejected Defaults (Budget as circular rings or green/yellow/red bars).
- No path, pid, upstream text or anyhow chain in a refusal or hint, and no bare "done" / "success" on `release --budget` (the line says what was lifted, until when, and who holds the wheel), per design-system §Anti-Patterns → Per-Surface Bans (cli).
- No human output from the hook arm: `viola hook` (the statusline arm's refusal included) writes nothing to stderr and has no human design surface, per design-system §Surface: cli → Platform-Specific Notes.

## Contract bindings
- design ↔ architecture: the refusal reason and detail words, exit 11 and the `--json` refusal object are architecture's closed enums; design-system §Surface: cli → Exit-code phraseology only prints them. design-system §Surface: cli → Component Patterns 2 records that exit 1 has no `--json` document until architecture amends it, which bounds what `revive`'s refusal may emit.
- design ↔ security: the no-`release` hint rule (T3), the no-path / no-pid / no-upstream-text rule and the per-cause strict-modes wording bind to security-plan's error-sanitisation floor, per design-system §Surface: cli → Component Patterns 2 and §Anti-Patterns → Per-Surface Bans (cli).
- design ↔ tests: the hint text and the `release --budget` line are fixed strings a test can assert whole; the scope's Path 6 signals on the hint (never `release`) and on the override line read these two sections (design-system §Surface: cli → Component Patterns 2 and 4).
- design ↔ obs: the log detail code for `revive`'s strict-modes refusal (`strict-modes-failed`) is obs-plan D-20's, named beside the human line in design-system §Surface: cli → Component Patterns 2.
- design ↔ layouts: the column placement of the `release --budget` line is the layouts distiller's (layout-templates); this extract carries its words only.
- design ↔ a11y: state is carried by the printed word, never by colour alone (SC 1.4.1), per design-system §Color Palette → Domain status colors; this chunk's lines carry no colour, so no contrast pair is added.
- Downstream readers (not built here): the snapshot's `budget_paused` is what the WHEEL cell rows `InstanceBudgetPaused::true` / `::false` print, and the `budget-gate` line's `paused` and `window` are what the tape row `EventKind::budget-gate` prints, per design-system §Color Palette → Domain status colors. That row names two printed forms (paused with its window, and open); which form an override record (`paused:false` with `override_until`) takes is not stated there.

## Acceptance criteria contributions
- A budget-refused `viola send` in human mode prints on stderr the `[/ ]`-prefixed `unable` line carrying the instance name, `budget-paused` and exactly one of `five-hour` / `seven-day`, then exactly one `hint:` line, and exits 11; stdout stays empty (per design-system §Surface: cli → Component Patterns 2 and §Surface: cli → Exit-code phraseology).
- The `budget-paused` hint contains no `release`, no sent or upstream text, no path and no pid; under `--json` no hint line is printed and the refusal is one JSON document on stdout (per design-system §Surface: cli → Component Patterns 2 and §Surface: cli → Tokens (Streams)).
- `viola release <name> --budget` in human mode prints one ASCII-only, unstyled stdout line holding the instance name, the gate-lifted phrase with the override's end as a UTC `HH:MM:SS` time ending in `Z`, and the current wheel holder (per design-system §Surface: cli → Component Patterns 4).
- A `viola revive` refused for strict-modes prints on stderr its fixed-message `unable: …` line followed by its one hint, with no recorded directory, pid or logged id in either line, nothing on stdout, exit 1 (per design-system §Surface: cli → Component Patterns 2 and §Surface: cli → Component Patterns 5).
