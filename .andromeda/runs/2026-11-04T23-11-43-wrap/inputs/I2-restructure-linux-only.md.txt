# Route adaptation — Viola becomes Linux-only

For a 0-pending `/andromeda-wrap-session` (operator-requested adaptation), run after `2026-11-04-linux-and-macos-parity` is
wrapped. Written 2026-11-04 by the Viola overseer. Entry TITLES are the anchors; re-read every coordinate at the run.

## The founder's ruling (his own words, this overseer's session and dialog, 2026-11-04 21:43Z)

«На самом деле меня заколебали уже вот эти война с этим Windows, MacOS и все такое … давай просто делать, чтоб только
целевая система была Linux [Arch] и все без Windows, MacOS … Когда будет хорошо работать на Linux, то подумаем делать
другие платформы или нет.»

By dialog the same evening, his chosen options:
- finish the current chunk first, then this adaptation;
- keep the Windows and macOS code in the tree but take it out of CI;
- drop «Windows-only live measurements», and make «Version done-check» Linux-only.

Why: every chunk pays for three OSes, the dev host is Linux (Arch, Omarchy) since 2026-10-03, and no Windows or macOS
host exists for a live reading. The product's target is now Linux alone, until it works well there.
