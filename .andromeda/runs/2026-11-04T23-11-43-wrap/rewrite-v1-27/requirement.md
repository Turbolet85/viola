`viola run <name> -- claude …` shows the child's screen and passes the human's keys exactly as without the wrapper, writing no bytes of its own to the terminal; it resolves the CLI to its real executable, strips the parent session's identity from the child, pins a copy of itself plus a freshly written plugin that hooks call by absolute path, starts in the documented order (collision check … events … child spawn), refuses a name that is already live or stale, and detects child exit on the process, never on end of output.
