**Dimension 4: GUI credential lifecycle**

**Dimension 5: Tier calibration and elevation coverage**
- The "integrity of `~/.viola/`" elevation is enforced differently on Windows and Unix.
  - The Unix strict-modes check covers the trusted files themselves: `snapshot.json`, `ledger/stamps.json` and the pinned `viola`.
  - The Windows owner + DACL check reads only directory DACLs. A Windows file can carry an explicit, non-inherited ACE, for example from `icacls` or an ACL-preserving restore or move. No directory check sees that ACE.
  - This matters most for `stamps.json`, which turns on dialog answering. It also matters for the pinned exe that Claude Code runs after the re-hash; that exe is never rewritten.
  - The Decisions Log entry names only "version folders" for Windows.
  - The elevation is under-enforced on the primary host OS, and the same control is described differently across sections. Patches 1 and 2 (Decisions Log companion).
- Over-engineering and SKIP markers: acceptable. No patch.

**Dimension 6: Anti-pattern centralisation (medium)**
- The output-encoding bans are already in § API, and the XFF ban has been reframed.
- The v1.x release-workflow bans in § Code Patterns duplicate the Decisions Log, but that is cosmetic. Moving them would be restructuring. No patch.

**Dimension 7: API hardening (medium)**
- Host edge cases, the `/assets/*`-only compression and the availability accepted risk are all stated. No patch.

## Patches

### Patch 1: Windows strict-modes check covers the trusted files, matching Unix
**Reason:** Dimension 5 (elevation "integrity of `~/.viola/`" enforced on Unix only for trusted files) and cross-section consistency (the Unix and Windows strict-modes scopes differ).
**Old:**
```
read the owner and DACL of the home, `instances/<name>/`, `bin/`, `plugin/`, `ledger/`, `ui/` and the `bin/<version>-<hash>/` and `plugin/<version>-<hash>/` folders the process uses or writes (each checked separately, because Windows bypass-traverse makes a subdirectory reachable regardless of the home's ACL) (windows-sys `GetNamedSecurityInfoW` + `GetAce`).
```
**New:**
```
read the owner and DACL of the home, `instances/<name>/`, `bin/`, `plugin/`, `ledger/`, `ui/`, the `bin/<version>-<hash>/` and `plugin/<version>-<hash>/` folders the process uses or writes, and the trusted files themselves (`snapshot.json`, `ledger/stamps.json`, the pinned `viola.exe`), matching the Unix list (each checked separately, because Windows bypass-traverse makes a subdirectory reachable regardless of the home's ACL, and a file can carry an explicit, non-inherited ACE that no directory check sees) (windows-sys `GetNamedSecurityInfoW` + `GetAce`).
```
