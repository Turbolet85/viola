## Patches

### Patch 1: Add the operational-metadata class to the consolidated NEVER-log floor
**Reason:** Dimension 1 (Downstream Readiness, obs) and Protocol step 2 (NEVER-log ↔ data classifications). The consolidated floor leaves out the TMS §1 operational-metadata class, where the OS username in absolute paths is the only PII. That makes Error Handling and § Logging stricter than the floor they are told not to diverge from.
**Old:**
```
  - `diagnostics/` files are 0600.
```
**New:**
```
  - Operational metadata (TMS §1): absolute paths, which carry the OS username (the only PII in scope), and internal type names never go to CLI `--json` error output, MCP `isError` results, Problem Details or channel `error.data`. The only intended path disclosure is the cookie-gated `/api/info` `viola_home`. Pids, `agent_session_id`, `started_at` and `budget.json` values may be written to `diagnostics/`.
  - `diagnostics/` files are 0600.
```
