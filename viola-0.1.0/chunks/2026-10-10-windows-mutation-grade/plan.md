## Constraints & rejected approaches
- A dispatch of `windows-mutants.yml` before the founder's own word — his ruling that it is dispatched only at
  the epoch boundary stands (`inputs#I3`); step 11.
- A kill sent at a process the test does not own (pid 4, the System process, was the first draft's candidate) —
  the operator's direction (`inputs#I3`).
- A case that kills a child the test starts and reads how long it stays in the process table — nothing holds a
  terminated process there for a time the test controls: a killed Unix child is a zombie, which `ProcessId::of`
  reads as gone (`harness/mod.rs`, "`None` when it is gone or a zombie"), and no user-mode hold exists on Windows.
  A test that only samples that window is a race (`testing.md` 2026-09-27: a timing window is forced, never
  sampled).
- An equivalence argument as a mutant's only closure — the run's verdict has no arm for it, and a list of argued
  mutants the harness subtracts would relax the mutation gate: the founder's, and he is away (`inputs#I1`).
- A raised ceiling — rejected for the per-file split (`inputs#I2`).
- The audit's recipe ported by hand — rejected for the revived syn reader (`inputs#I2`).
- A `rustc --print cfg` child for the host's facts — a new process spawned by the harness, where its own
  constants answer the three keys the workflow's predicates use.
- Leaving a host-excluded mutant out before the run (`--exclude-re`) — it would save about 13 mutants' time in
  the `viola` jobs, which the split no longer needs, and it changes the command line the contract documents.
- A dispatch input to re-run one job — the workflow takes no `inputs:` (architecture §Infrastructure Patterns →
  CI/CD approach), so a dispatch runs all nine.

  strict-modes check until the route entry "Home and code-bearing file integrity"; the tests assert at
  `check_path` and `check_stamps`.

  nor G4; a booted one could, and no further carve-out is available.
- A new `event`, `detail`, `verdict`, `reason` or `suite` value, a new environment variable, a new agent
  command, a mutation job in `ci.yml` — each needs a Decisions Log entry or a ruling this chunk may not seek.
