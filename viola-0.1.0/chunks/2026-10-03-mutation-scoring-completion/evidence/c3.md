# C3 — the harness diff-prefix pin

Host: Linux, git 2.55.0. The host's global git config sets `diff.mnemonicprefix=true` (`~/.config/git/config`).

## The fix
`crates/viola-e2e/src/harness/run/mutants/base.rs` `chunk_diff`: `--src-prefix=a/ --dst-prefix=b/` on both `git diff`
argvs (the merge-base diff and the per-untracked-file `--no-index` diff). `diff_paths` / `diff_files` unchanged.

## The witness under the host config

`ok:true`, nextest-unit **43 passed / 0 failed** (archive 17). P5's baseline under the same config read 29 / 13; the
selection is one test larger now (the new hostile-config test).
