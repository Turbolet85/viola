2. **`scripts/install-node.sh` (new).** One bash script that CI (on all three OSes, under the runner's bash) and
   `wsl-provision.sh` both call.
   - **Arguments:** `install-node.sh <os-key> <dest-dir>`, where `<os-key>` ∈ `linux-x64 · darwin-arm64 · win-x64`.
   - **Reading the pins:** it reads `NODE_PIN_VERSION` and `NODE_PIN_SHA256_<KEY>` by parsing `.github/workflows/ci.yml` text,
     never the environment. It never restates a value.
   - **Install:** downloads `https://nodejs.org/dist/v<ver>/node-v<ver>-<os-key>.<ext>` with the same curl retry flags as
     rustup-init. It verifies the file with `sha256sum`, falling back to `shasum -a 256`. It extracts to `<dest-dir>`
     (`tar -xJf` / `tar -xzf` / `unzip -q`).
   - **Output:** prints exactly one line, `install-node: <bin dir>`, where the bin dir is `<dest-dir>/bin` on unix and `<dest-dir>`
     on win-x64.
   - **Refusals:**
     - a checksum mismatch → `install-node: checksum mismatch for <file>`, exit 1, nothing extracted;
     - an unreadable pin → `install-node: pin-unreadable`, exit 1;
     - usage → exit 2.
   - **`--probe`:** proves the checksum refusal on a tampered file and the pin parse against the real `ci.yml`. It prints
     `install-node --probe: 1/1 refused, pins ok v<ver>`, never downloading (the `wsl-provision.sh` probe shape, lines 112–133).
