## Goal
`viola list` learns what the disk cannot tell it. It runs `claude agents --json` once, joins the rows to the wrapped
instances, and gives each joined wrapped row STATUS `idle` or `busy`. Every row that joins no wrapped instance prints
as a read-only unwrapped row, under `-- UNWRAPPED - READ-ONLY --` on the human board and as a `wrapped: false` item in
`list --json`. A failed, oversize or malformed read changes nothing that `list` prints today
(architecture §Standard Contracts, Session liveness and the `list` payload; design-system §Surface: cli, pattern 1;
layout-templates §Output structure — `viola list`).

`viola revive` gains its fourth preflight reading, `session-live`. The same read refuses a resume of a session id that
a live `claude` already holds. `--fork` skips the reading, and a failed read fails open (architecture [Session
Liveness]; the founder's answers, `inputs#I1` forks 3 and 4).

The join field becomes the twenty-third capability-ledger row, `agents-join`, relied on every OS. Its `viola verify`
probe is one bounded `claude agents --json` read taken while Run B's session is live (`inputs#I1` fork 1). The fake
agent answers `agents --json` from files beside its own executable, with no env (`inputs#I1` fork 2). The parser takes
a 512-case property and a fuzz target. One recorded `claude agents --json` row is committed under
`fixtures/claude/2.1.287/`. Two live legs are spent: the record round (6 starts) and the P4 / P12 leg (2 starts), the
founder's cap of 8 (`inputs#I1` fork 3).

## Implementation Steps
1. **The agents reading** — new `crates/viola-agent-claude/src/agents.rs`, pure, no I/O. It is re-exported from
   `crates/viola-agent-claude/src/lib.rs`.
   - **The row type.** A tolerant row over the measured keys (`pid`, `sessionId`, `status`, `kind`, `cwd`, `name`,
     `startedAt`). It uses `#[serde(default)]` / `Option<T>`, never `deny_unknown_fields`, and keeps the raw `Value`
     for the recorder (architecture §Established Decisions [Validation]).
   - **`parse(bytes) -> Result<Vec<AgentsRow>, AgentsFailure>`.** It returns `Oversize` above `MAX_FRAME` and
     `Malformed` for anything that is not one JSON array at serde's default depth. An element that is not an object,
     or has no string `sessionId`, is skipped and counted.
   - **The status mapping.** A closed status, idle · busy · unknown, mapped one to one from the measured `status`
     words. Any other value is unknown.
   - **The join predicate.** A row joins a wrapped instance when its `pid` equals that instance's `child_pid`, or its
     `sessionId` equals its `agent_session_id`.
   - **A row's `sessionId` is content.** It is never a `ViolaName` (security-plan §Security Anti-Patterns, Input).
   - **Unit cases:**
     - the measured 7-key row;
     - an extra key, kept and counted as tolerated;
     - a `background` row of the `--all` shape (no `pid`, no `status`): listed with status unknown, joinable only by
       `sessionId`;
     - a row with no `sessionId`, skipped;
     - a non-array document and a non-UTF-8 document;
     - the `MAX_FRAME` boundary (`MAX_FRAME` bytes parse, `MAX_FRAME + 1` is `Oversize`);
     - every measured `status` word and one unknown word.
2. **The property and the fuzz target** (test-plan §6 Property suite; §2 Property-based row).
   - A proptest over arbitrary JSON values, `cases: 512`, in the agents module. `parse` never panics. It returns
     either rows or a closed failure, and every returned row's `sessionId` is a string taken from the input unchanged.
   - Its regressions file is `crates/viola-agent-claude/proptest-regressions/agents.txt`, committed once proptest
     writes it.
   - New `fuzz/fuzz_targets/claude_agents_json.rs` with a `[[bin]]` in `fuzz/Cargo.toml` (the crate already
     path-depends on `viola-agent-claude`) and `fuzz/Cargo.lock` following.
   - A synthetic corpus in `fuzz/corpus/claude_agents_json/`: the measured 7-key shape with invented values, the
     `--all` background shape, an empty array, a non-array, a deep array and a row whose `sessionId` holds control
     characters. The count is stated by `ls fuzz/corpus/claude_agents_json | wc -l`. No recorded content.
   - `.gitattributes` gains `fuzz/corpus/claude_agents_json/** binary` (the `paste_text` precedent,
     `.gitattributes:6`).
3. **The bounded read** — new `src/run/agents.rs`, a module of `src/run/mod.rs`, beside the version gate.
   - It resolves `claude` through `run::resolve_program`, the same rule as `run`'s (a `.cmd` / `.bat` shim to its
     `claude.exe`; any other batch script refused). A refusal or a missing program is a failed read, never an exit
     change.
   - It spawns `claude agents --json` directly under the same `StripPlan` the version gate builds, with stdin null,
     killed and reaped at `VERSION_DEADLINE`.
   - It reads stdout through `take(MAX_FRAME + 1)`. Either `run_bounded`'s drain in `src/run/version_gate.rs` gains
     the over-the-cap flag, keeping its two callers' readings unchanged, or the agents read takes its own drain. A
     non-zero exit is a failed read.
   - It returns the rows, or a closed failure word: `oversize` · `malformed` · `unreadable` (spawn failure, deadline,
     non-zero exit, refused resolution).
   - The callers log the spawn pair at their own sites (obs-plan §6, Boundary-call wrappers):
     - `process-start{subject:"agents-probe"}` and `process-exit{subject:"agents-probe", child_exit_status,
       duration_ms}`, with no row text, id, `cwd` or path;
     - on a parse failure one `parse-rejected{parser:"claude-agents-json", detail, count}` at `warn`;
     - `run_bounded` stays unlogged.
   - No line is written where the caller has no open log (`list` with no `VIOLA_NAME`).
4. **The snapshot's session id.** `crates/viola-state/src/snapshot.rs` `InstanceSnapshot` gains `agent_session_id:
   Option<String>`, additive (`#[serde(default, skip_serializing_if = "Option::is_none")]`). The wrapper rewrites it
   whenever the hook tap takes a `session-start` whose `agent_session_id` is a string. A `session-start` with no string
   id leaves it as it stands. The tap is `append_hook_event` in `src/run/send/slot.rs`, and the write goes through the
   wrapper's snapshot handle (`src/run/snapshot.rs` `update`), after the line is appended. Unit cases: a `startup`
   then a `clear` start rewrites the field twice, and a start with a null id writes nothing.
5. **The board's read model** (`crates/viola-state/src/board.rs`; it takes no agent-crate type — architecture
   §Infrastructure Patterns → Crate dependency direction).
   - `SessionStatus` gains `Idle` and `Busy` (kebab `idle` / `busy`).
   - `read` also gives each wrapped item's join keys: the snapshot's `child_pid` and `agent_session_id`, and for a
     replayed instance the replay's `agent_session_id` with no pid. They are not serialised.
   - A new constructor builds an unwrapped item: `wrapped: false`, `liveness` `live`, `dialog_pending: false`, and no
     `wheel` / `budget_paused` / `cli_version` / `cli_verified` key (architecture §Standard Contracts, `list` payload).
   - A join takes plain observations: a pid, a session-id string and a status. For each wrapped item it sets the
     joined observation's status. Every observation that joins no item becomes an unwrapped item. Unwrapped items are
     sorted by name and placed after every wrapped item.
   - Liveness is never changed, and a gone instance is never brought back (architecture [Session Liveness]).
   - Unit cases: a pid join; a session-id join; a row matching neither; one row matching two keys of one item (one
     join, no unwrapped row); a stale wrapped item joined keeps `stale`; the unwrapped item serialised to its contract
     literal.

   - **What a refusal writes.** One `process-exit{subject:"self", exit_code:1, detail:"session-live"}`, no child,
     exit 1, and nothing on stdout (design-system §Surface: cli, pattern 2; layout-templates §Output structure —
     `viola revive`).

- **The CLI's `name` as the unwrapped NAME.** Rejected because it is a free-text title (user content), and the cli
  bans upstream text on the board.
- **A `FAKE_CLAUDE_AGENTS_MODE` env seam.** Rejected by the founder (`inputs#I1` fork 2): the files beside the exe.

  P12 is measured in the P4 leg.
- **Reading `~/.claude/sessions/`, the CLI's own registry.** Rejected: viola reads and writes nothing under
  `~/.claude`, and the read is the documented subcommand.
- **Gating `list`'s or `revive`'s read on the stamp of the `claude` on `PATH`.** Rejected: architecture makes the
  read an enrichment whose failure is never an error. The stamp gates the wrapped instance's own `cli_verified`.

- **Converting `session-live` to a warning on a P4 reading.** Not this chunk: a new route entry (`inputs#I1` fork 3).
