## Constraints & rejected approaches
- A survivor recorded as "equivalent" or disposed by argument — test-plan §10 Mutation gate names one disposition
  that is not a kill, for a mutant this host cannot compile or reach, "never "equivalent""; `inputs#I2` chose
  restatement for all four.
- A bare `cargo mutants` over a root-package file — with the default target dir root integration tests drive the
  unmutated binary (architecture §Occupied Resources (Repository), `target/mutants/`); every run is the harness arm.
- A mutation run as a `[[gate]]` entry, a pre-push stage or a workflow job — `inputs#I1`; the mutation gate is the
  boundary's.
- Two mutation runs at once, or a full suite or `pre-push` beside one — they share `target/mutants` and the
  scratch, and a loaded host turns a caught mutant into a timeout.
- A new environment seam, fake-agent option, feature or dependency to make a mutant observable — the seam list is
  closed at two and a third is a founder-level widening (security-plan §Security Anti-Patterns → Universal).
- A forced panic to reach a branch in a scanned home, or a second caller of `TestHome::outside_scan()` — G2 counts
  every panic line but the seam's own.
- A test aimed at a helper split out in section B — the kill cases drive `dialog_variants`, `submit`, `run_hook` and
  the public readers, never a split-out helper (test-plan §11 Test Anti-Patterns → Unit).
- An upper bound on a wait as an assertion — the two timed fake-agent cases assert that a hold was at least its
  length, never that something was fast.
- Healing, rewriting or newly reporting a torn line in `events.rs` — owed to "Self-healing state".
- Reshaping a body out of cargo-mutants' generated set (a function turned into a closure, a `#[cfg]` moved) —
  testing.md 2026-09-28; the four restatements keep every body mutated.
- A helper in `src/run/send.rs`'s inline test module — its case counts are pinned by three earlier plans and the
  preservation guard holds the file.
- One helper that folds the piped and the outer-PTY runners, or the Linux and Windows arms of a wheel case — they
  are different measurements by design (a11y-plan §3 Keyboard test harness).
- A raw `outcomes.json`, a `mutants.out/` directory or the scratch path in `evidence/` — it holds absolute argv
  paths.
