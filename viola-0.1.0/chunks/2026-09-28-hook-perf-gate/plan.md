## Goal
`viola hook`'s deadlines become a gated CI verdict. A named-only `run --perf` harness arm builds the non-instrumented
`target/perf` release, boots one perf session, and times the real `viola hook` binary with hyperfine 1.20.0 for the
four test-plan §10 rows that exist at HEAD. It writes `target/agent-run/artifacts/perf-<hook>.json`. A new per-OS
`perf` CI job ends in `gate --require perf`, which now requires every named row and breaches on a `max` at or over the
provisional 1.0 s (per test-plan §3 `run`/`gate`, §9 Perf row, §10; obs-plan §10). Neither deadline is retuned: a
breach is surfaced, never absorbed (test-plan §10 Verdict; architecture [Hook Transport]).

The fail-open contract is proven on its weakest path. `FAKE_AGENT_HOOK_PANIC=1` is compiled only under `fake-agent`,
was ratified by the founder live on 2026-09-28 (relay: the Viola overseer), and forces the real binary to panic
after log init. The process still exits 0 with empty stdout and stderr. It leaves one payload-free `event:"panic"`
role line and one detail line over 4 KiB (per security-plan §Error Handling, §Security Anti-Patterns → Universal;
obs-plan §7; test-plan §6 Security sweep). The same line closes obs D-28's concurrent-append half on all three OSes
(obs-plan §3). CI's G2 keeps full strength: it exempts exactly the seam's own file, and a `--probe` proves that any
other location still fails. The seam's first `tests/cli_controls_not_disableable.rs` row shows that no
disabling-shaped value of the variable disables a hook-path control (test-plan §5 Vector 6, interim shape).

Three P4 forks were decided by the operator, with the overseer's notes: (1) perf runs in its own per-OS job, so
`test`, pre-push and WSL stay untouched and CARRY 3 moves on; (2) G2 exempts the seam's exact file path, with a
known-positive control that any other file still fails; (3) the controls file lands now with the hook-path controls,
and test-plan §5 records the interim shape at wrap.

## Implementation notes
- **Symbolisation cost.** The forced-panic case keeps the 1 s bound. `force_capture()` symbolisation cost on a Windows
  debug build is unmeasured (research). If the case breaches, that is a finding to surface, never a raised bound or a
  moved assertion.
- **Stdin write races the panic.** The seam fires before stdin is read, so a child may exit before the test's stdin
  write lands. The concurrent test's writes must tolerate `BrokenPipe` (unlike the existing check's `.expect` at
  `tests/hook_fail_open.rs:271`).
- **Command shape under `-N`.** hyperfine splits the command on whitespace, so `<exe>` must hold no space: the
  repo-relative form does not, on this host or on CI runners. Record the exact hyperfine argv in
  `evidence/perf-argv.md`.
- **Local homes accumulate.** Local `target/e2e-home` keeps homes across runs under `AGENT_RUN_KEEP_HOMES=1`. A red G2
  entry locally names its file; a panic line from an older home, such as the kept control home
  `viola-session-NETvJg`, is surfaced to the operator, never deleted to reach green.
- **Growth.** CI grows from 8 jobs / 15 check-runs to 9 jobs / 18 check-runs (basis: architecture sidecar
  `2026-09-24-workspace-tree-and-code-graph-planes`, "8 jobs, 15 check-runs", plus three perf legs).
- **CARRY 3 moves on.** It does not fire (operator fork 1: no re-provision): the wrap moves it to the next markerless
  entry.
- **Matrix.** No capability is claimed. v1-05 still needs "no setting disables redaction" (no redaction-bearing setting
  exists); v1-07 still needs the remaining security-named parser surfaces. This chunk closes their hook-panic and
