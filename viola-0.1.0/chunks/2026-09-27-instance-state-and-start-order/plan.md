## Goal
`viola run` gains its instance state and the start order around the spawn. A new sync crate, `viola-state`, carries
the generic disk primitives: owner-only creation, one shared atomic-replace helper, the append-only event line writer,
the snapshot envelope, the heartbeat touch, the pid + start-time liveness classifier, and the pinned exe copy with its
truncated SHA-256 key and re-hash (per architecture §Standard Contracts, §Occupied Resources → Filesystem,
§Established Decisions [Session Liveness] / [Deployment / Distribution]; security-plan §Data Protection).

`viola run` then runs the documented order (arch `architecture.md:92`): program resolution (the existing `.cmd`
refusal, which writes nothing) → collision check → pinned copy + plugin folder → version-gate slot → bind slot (the
channel chunk's) → first snapshot + heartbeat → start `wheel` + `budget-gate` events → spawn with `VIOLA_NAME` /
`VIOLA_DIR` / `VIOLA_BIN`, the `PATH` prefix and `--plugin-dir` → the snapshot rewritten with `child_pid`. A live or
stale name refuses with exit 1, and a gone one is taken over and appended to. A pinned copy that fails its re-hash
refuses with exit 1. Each refusal has design's fixed line and its own hint, and the obs `detail` code (design-system
§Surface: cli → Component Patterns 2; obs-plan §6 `detail` catalog; test-plan §6 exit-cause matrix).

Two operator rulings at P4 shape it. The atomic primitive is tempfile `persist`, because atomic-write-file 0.3.1 is
BSD-3-Clause and outside `deny.toml`'s allow list (research §Measured facts). The embedded plugin ships with an empty
`hooks` / `mcpServers` body, because no `hook` / `mcp` verb exists and a registered hook would exit 2. Both CARRYs
land here: sha2 becomes `viola-state`'s normal dependency behind the re-hash refusal test, and E2's `VIOLA_*`
presence half lands.

### Part A — `viola-state` primitives (steps 1-7)

   `edition.workspace`, `rust-version.workspace`, `[lints] workspace = true`, `[features] fake-agent = []`, and
   dependencies `viola-core` (path), `chrono`, `serde`, `serde_json`, `sha2`, `sysinfo`, `tempfile`, `thiserror`,
   `tracing` (all `.workspace = true`). Put `tempfile` under `[dependencies]` because it is the product's atomic
   helper, and keep it in `[dev-dependencies]` elsewhere. Add `crates/viola-state/src/lib.rs` with an inline
   `mod tests`. Add a `StateError` thiserror enum with fixed `Display` strings that name no path and no payload
   (security-plan §Error Handling). Add `viola-state` to `scripts/sync-crates.txt`, and add
   `viola-state = { path = "crates/viola-state" }` to the root `[dependencies]` in `Cargo.toml`. The root keeps
   `sha2` as a dev-dependency for `tests/contract_content_hash.rs`.
2. **Owner-only creation and the ONE atomic helper** (a `fs` module in `viola-state`):
   - `create_private_dir(path)`: `create_dir_all`, then on Unix an explicit `set_permissions(0o700)` on every
     component the call created under the given root. Use the `src/obs.rs:39-45` pattern.
   - `open_private_append(path)`: `OpenOptions::append` + `create`, Unix `mode(0o600)`, then an explicit
     `set_permissions(0o600)`. Use the `src/obs.rs:52-60` pattern.
   - `replace_private(path, bytes, mode)`: the single shared atomic helper (operator ruling: one helper, never
     per-site copies). It does `tempfile::NamedTempFile::new_in(parent)` → Unix `set_permissions(mode)` on the temp
     file BEFORE any write → `write_all` → `sync_all` → `persist(path)`. A failure at any stage returns `StateError`
     and leaves the target untouched.
   - Point `src/obs.rs`'s two private helpers at these functions, so one implementation serves both, and keep their
     call sites and their tests green.
3. **Event line writer** (an `events` module):
   - `EventLine { v: 1, ts, instance: ViolaName, kind, source, data }` serialised as one compact JSON object.
     `ts` is RFC 3339 UTC ms + `Z` (`to_rfc3339_opts(SecondsFormat::Millis, true)`). `source` is kebab-case, and
     this chunk uses `wrapper` only.
   - Add the two start kinds as the first variants of a closed kebab-case `EventKind` enum in `viola-core`: `wheel`
     and `budget-gate`. Arch `architecture.md:160`: "New kinds are added only in `viola-core`". The other kinds
     arrive with their chunks.
   - `append_event(instance_dir, &EventLine)`:
     - take an exclusive `File::lock` on `events.ndjson.lock` (0600, created with `open_private_append`);
     - open `events.ndjson` with `open_private_append`, and make one `write_all` of the line + `\n`;
     - never truncate or rewrite an existing file.
4. **Snapshot envelope** (a `snapshot` module):
   - The envelope is `{v:1, written_at, writer: VERSION, data}`. `InstanceSnapshot` has these fields:
     - `endpoint: Option<String>` (skipped when `None` until the channel chunk);
     - `pid: u32` and `started_at: String`;
     - `pinned_bin: String` (forward slashes);
     - `cli_verified: bool` and `cli_version: Option<String>` (skipped);
     - `wheel` (`driver` | `human`, kebab-case);
     - `budget_paused: bool`, `links: Vec<…>` (empty) and `child_pid: Option<u32>` (skipped until set).
     `statusline_command`, `pending_dialog`, `budget_override_until` and `agent_session_id` are not added until
     their chunks (additive, arch §Conventions).
   - `write_snapshot(instance_dir, &InstanceSnapshot)` holds an exclusive lock on `snapshot.json.lock` and calls
     `replace_private(…, 0o600)`.
   - `read_snapshot(instance_dir) -> Option<InstanceSnapshot>` reads through `Read::take(MAX_FRAME)` with serde's
     default depth. A missing, unreadable or unparseable file → `None`. Self-healing is Epoch 4's.
5. **Heartbeat** (a `heartbeat` module):
   - `touch_heartbeat(instance_dir)` opens or creates `heartbeat` (0600) and sets its mtime to now
     (`File::set_modified`).
   - `beat_age(instance_dir, now) -> Option<Duration>` gives `now − mtime`, and `None` when the file is absent.
   - `Heartbeat::start(instance_dir)` spawns one std thread that touches the file every 1 s until the returned
     guard is dropped. The guard drop signals through a channel's `recv_timeout(1 s)` and joins the thread.
   - A failed touch is swallowed: no log line per tick (obs-plan §3 Heartbeat ticks, §11 SLO).
6. **Liveness** (a `liveness` module):
   - `Liveness { Live, Stale, Gone }`.
   - Pure `classify(beat_age: Option<Duration>, same_process: bool) -> Liveness`. `same_process == false` → `Gone`.
     Otherwise, `beat_age` ≤ 5 s → `Live`, and older or absent → `Stale`.
   - `process_start_time(pid) -> Option<u64>` is the sysinfo read ported from `ProcessId::of`
     (`crates/viola-e2e/src/harness/mod.rs:149-159`: `refresh_processes(Some(&[pid]), true)`, not a zombie,
     `start_time()`).
   - `own_start(pid)` renders those seconds as the snapshot's RFC 3339 `started_at`. `same_process(snapshot)`
     parses `started_at` back to seconds and compares it with `process_start_time(snapshot.pid)`.
7. **Pinned copy** (a `pin` module):
   - `content_key(bytes) -> String` = `hex(sha256(bytes))[..16]`, the recipe `tests/contract_content_hash.rs` pins.
   - `pin_exe(home, exe_path) -> Result<Pinned, PinError>`:
     - reads the running exe's bytes and computes `key = VERSION + "-" + content_key`;
     - creates `bin/<key>/` (0700) and uses `bin/<key>/viola` (`.exe` on Windows);
     - when the file exists, re-hashes it, and on any byte difference returns `PinError::HashMismatch` without
       touching it;
     - when it is absent, writes it with `replace_private(…, 0o700)`.
   - `Pinned` carries the key, the absolute path and its forward-slash form.

### Part B — the start order in `viola run` (steps 8-14)

9. **Collision check in `src/cmd/run.rs`**, after `resolve_program` and before any write:
   - `instance_dir = home/instances/<name>` (joined only from the `ViolaName`). `read_snapshot` → `None` means
     free.
   - Otherwise `classify(beat_age(…), same_process(&snap))`:
     - `Live` → `refuse_live(name)`: `unable: <name> is already live` / `hint: viola list`;
     - `Stale` → `refuse_stale(name)`: `unable: <name> is still running but not answering` /
       `hint: viola list shows it as stale; stop that process before starting <name> again`;
     - both → `log_self_exit(1, Some("already-live"))` and exit 1;
     - `Gone` → proceed and reuse the directory.
   - Refusal lines use `writeln!` on the locked stderr like `refuse_batch_script` (`src/cmd/run.rs:107-115`), with
     no path and no pid.
10. **Pinned copy + plugin folder** after the collision check:

      `hint: the pinned copy was changed after it was written, so viola will not run it`,

- `settings.json` — not written here. It is "Statusline pass-through"'s (working-route:67).

- Printing progress or any viola byte to the terminal during start — banned (layout-templates §Output structure — `viola run`; a11y-plan §3).

## Implementation notes
