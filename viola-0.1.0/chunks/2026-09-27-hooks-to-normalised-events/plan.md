## Goal
The `claude` child's hooks reach viola's event log. The embedded plugin registers exec-form hooks by the absolute pinned path
(architecture [Hook Transport], [Deployment / Distribution]). A new hidden verb, `viola hook <event>`, reads the hook payload
under `MAX_FRAME` and parses it tolerantly in `viola-agent-claude`, the only crate that knows Claude shapes. It maps the payload
to a normalised kind from `viola-core` (architecture §Conventions Hook → kind map; §Standard Contracts Event `data` per kind)
and hands it to the wrapper as the id-less `hook.event` notification. The wrapper appends it to `events.ndjson` with
`source:"hook"`. `prompt-submitted` text is unwrapped from the CLI's long-paste wrapper and then un-escaped, and harness turns
are classified `harness` (architecture [Delivery Confirmation]; ledger rows at architecture.md:80–89).

`viola hook` fails open on every path. It exits 0, writes nothing to stdout or stderr, and a hook outside a wrapped session
writes nothing anywhere (architecture [Hook Contract]; security-plan §Error Handling; obs-plan §4 E1). This takes three
mechanisms that `run` alone never needed:
- the pre-clap role classification at the main-thread catch site;
- a sink fallback when the role file will not open;
- the first `drift_report` producer (obs-plan §7, §8; CARRYs 1 and 2).

Concurrent hook processes are the first shared writers of `hook-<name>.ndjson` and `detail-hook.ndjson` (obs-plan D-28). The
SessionStart hook reads `snapshot.json` exactly while the wrapper writes its second snapshot. So the one atomic replace gains a
bounded retry on the Windows refusal measured at P3 (CARRY 5; research.md M1–M2).

**Interim gap (operator ruling, fork 2):** until the Epoch 6 entries land, a hook trusts the endpoint recorded in
`snapshot.json`, with no server verification and no home strict-modes. The first-instance pipe and the bind arbiter already stop
a squatter from taking a live name.

6. **Hook payloads (`viola-agent-claude`).** A new module, `crates/viola-agent-claude/src/hook.rs`, declared from `lib.rs`.
   Add `serde`, `serde_json` and `serde_path_to_error =0.1.20` (architecture.md:24; new to `[workspace.dependencies]`), plus
   `viola-core`. It holds:
   - **`HookEvent`:** the closed set of `hook <event>` arguments this chunk registers: `session-start`, `user-prompt-submit`,
     `stop`, `session-end`, `notification`, `post-tool-use`, `post-tool-use-failure`. `from_arg(&str) -> Option<Self>`, the
     `as_str` kebab name (equal to diag-line `$defs.hook_event`), and `is_spine()`.
   - **Tolerant parse:** the stdin bytes must be one JSON object, otherwise the error is `Malformed`. Known fields read through
     a typed view with `#[serde(default)]` / `Option<T>` and no `deny_unknown_fields`: `session_id`, `source`, `prompt`,
     `last_assistant_message`, `tool_name`. The view is deserialized with `serde_path_to_error`. When a known field has the
     wrong type, the result keeps a drift report — `{"path": <field path>, "expected": <fixed type word>}`, never the value —
     and treats that field as absent.
   - **Normalise to `(EventKind, data)`** per architecture.md:163–170 and 280–288:
     - `session-start`: `{cause, agent_session_id}`, with `cause` from `source` ∈ startup·clear·resume·compact, else
       `unknown`, and `agent_session_id` a string or null;
     - `prompt-submitted`: `{text, origin}`;
     - `turn-ended`: `{last_assistant_message}`, a string or null;
     - `session-end`: `{}`;
     - `activity`: `{}`, plus `tool` when `tool_name` is a string.

     No raw payload field is ever copied into `data` whole.
   - **Prompt normalisation, in this order:**
     1. Classify: `origin` is `harness` when the RAW prompt starts with `<agent-message from=` or `<task-notification>`,
        before any rewrite. A user-typed prefix arrives escaped (`<\task-notification>`), so it never classifies. Otherwise
        `human`: no driver path exists before :58 (scope.md item 3).
     2. Unwrap only the CLI's UNESCAPED pair, measured (research.md M5): `<pasted_content id="X">` + `\n` … `\n` +
        `</pasted_content id="X">`, the same X on both tags. Replace each such pair, tags and those two inner newlines, with
        its inner text. Text outside a pair, including the measured leading `\n\n` and trailing `\n`, is kept byte for byte. An
        unmatched tag, or a close with another id, is not a pair and is left as is.
     3. Un-escape both TYPED forms: `<\` directly followed by an ASCII letter → `<` (`<\pasted_content` → `<pasted_content`),
        and `<\/` → `</` (`<\/pasted_content` → `</pasted_content`). Because it runs after step 2, a typed pair is never
        unwrapped (architecture.md:89).

     The text is never interpreted (security-plan §Security Anti-Patterns → Code Patterns).
   - **Errors:** one fixed-message `thiserror` enum (security-plan §Error Handling).

## Constraints & rejected approaches
- Server verification or strict-modes in this chunk — rejected by operator ruling (fork 2). The Epoch 6 entries own them, and
  the hook must not grow a partial verifier.
- A committed `fixtures/claude/` file — rejected by operator ruling (fork 3). Recorded fixtures are `viola verify`'s (:51), and
  this chunk's fixtures are written by the tests.
- Registering the dialog tier (PreToolUse, PermissionRequest) with a no-decision body — rejected. It needs `hook.dialog`,
  `dialog_id` and the dialog kinds (:62). A premature entry would also mint `question`/`permission` lines no reader can pair.
- Classifying `harness` after un-escaping — rejected. The raw prefix is the only signal that a user typed nothing: a typed prefix
  arrives escaped.
- A hook that prints anything: a hint, `error: internal error`, clap usage, SGR — rejected (design-system Exit-code phraseology
  row 2; obs-plan §11). The `cli` catch-site print is :49's.
- A retry keyed on `ERROR_SHARING_VIOLATION` (32) only — rejected. The measured refusal is 5 under every share mode (M1).
- A time-based retry bound or a `sleep`-synchronised witness — rejected. The bound is an attempt count, and the witness releases
  the holder from the pause callback (testing.md §Determinism; 2026-09-27).
- A hook-side retry or wait for a busy wrapper past 750 ms — rejected. The event is lost rather than the turn delayed
  (architecture.md:64).
- Putting `--perf`, hyperfine or a perf CI job in this chunk — rejected by operator ruling (fork 1). They go to the tail entry.
- A panic trigger of any kind (an env var, a feature-gated flag, a fake-agent switch), `FAKE_AGENT_HOOK_PANIC` included —
  rejected at the P5 review. A new seam is a boundary widening that only the founder's live answer ratifies; it is CARRYd to the
  tail.
- Unwrapping an escaped pair (`<\pasted_content …>`), or a bare `</pasted_content>` close — rejected. The CLI's pair is
  unescaped and repeats the id, and an escaped pair is typed text (M5; store.rs:241–249).
