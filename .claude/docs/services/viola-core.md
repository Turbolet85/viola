# viola-core

_Crate implementation notes. Primary source: `.andromeda/architecture.md` (§Crate dependency direction, §Conventions); security §Input Validation; obs §3 Logging stack. Generated by `/andromeda-setup-project`._

## Responsibility
The shared vocabulary of every other crate: the normalised event kinds, `RefusalReason` and its closed detail sets (`HumanTyping { ManualPause }` among them), `UnreachableCause` (`StrictModes` · `InstanceDead` · `UnwrappedName` · `EndpointLost` · `ServerVerify`, each word through `as_str`: exit 21's closed cause set, with no serde path, the two clients writing every word, and no `RefusalReason`), the wheel's `WheelCause` (`start` · `human-input` · `manual-pause` · `release`), the nutype newtypes `ViolaName`, `Percent` and `DialogHold` (whole seconds 60–3600), the protocol `v` constants, the shared validators (`validate_paste_text`, and `is_code_word`: 1 to 64 bytes of `[a-z0-9-]`, a lower-case letter first), the `MAX_FRAME` constant (16 MiB), `SPINE_DEADLINE` (1 s, the spine bound the perf gate reads), `DIALOG_HOLD_DEFAULT` · `DIALOG_HOLD_MIN` · `DIALOG_HOLD_MAX` (60 s · 60 s · 3600 s, PROVISIONAL: the dialog hold's default and bounds, `config.json`'s `dialog_hold_s` read once at the wrapper's start into a `DialogHold`; the hook bounds its reply read at `DIALOG_HOLD_MAX + 5 s`, below the `hooks.json` `timeout` of 3615), the injected `Clock` seam (`SystemClock` in production; first consumer `run`'s vt100 feed thread), `SERVICE_NAME` / `VERSION`, and the obs vocabulary (`obs_event!`, `ObsEvent`, `ObsProcess`). It performs no I/O and depends on no viola crate. It does NOT know Claude payload shapes (that is `viola-agent-claude`), and it does not depend on `tracing`: `obs_event!` expands to `::tracing::event!` at the caller.

## Key integrations

### Consumes from
Nothing inside the workspace. Third-party: nutype 0.8.0 (`ViolaName`, `Percent`, `DialogHold`) and serde (`derive`), with the dev-dependency serde_json (via `[workspace.dependencies]`).

### Publishes to
Every workspace crate and the root bin: event kinds (kebab-case wire values), `RefusalReason` (`#[serde(other)] unknown`), newtypes, validators, constants.

### Dependencies
None beyond the workspace-shared third-party crates; tokio is banned in its graph (the sole-root `deny-sync.toml` ban; `viola-core` is listed in `scripts/sync-crates.txt`).

## Internal conventions
- New event kinds and refusal details are added ONLY here, never with Claude-specific names; `detail` values are kebab-case strings from a closed set per reason (`unknown`'s a code word or null). `EventKind` holds 16 kinds (the length of `EventKind::ALL`), the dialog kinds `question` / `permission` / `plan` among them, `link` / `unlink` (`data` keys `driver`, `driven`) and, last, `dialog-expired` (`data` keys `dialog_id`, `dialog_kind`; `source: wrapper`, appended once when a held dialog's hold ends); `EventKind::WAIT_WAKE` is the one wake set (`turn-ended`, `question`, `permission`, `plan`, `session-end`, `dialog-expired`) the wrapper's `wait` and the channel's `outcome` both read.
- `validate_paste_text(&str) -> Result<(), NotDelivered>` checks decoded `char`s: LF/CR/TAB allowed; every other C0, DEL and C1 → `not-delivered` / `control-character`. Called by the CLI (and by `viola mcp`, which logs one client-side `send-refused` per refused `send` text) client side and again by the wrapper (authoritative). `RefusalReason` and the closed `not-delivered` details `NotDelivered` (six values, `empty-text` the sixth: an empty typed text on `send`) are kebab-case serde enums with `as_str`; `EventKind` carries the three `send-*` kinds.
- The budget reading: `BudgetReading {five_hour, seven_day}`, each a `BudgetWindow {used_percentage: Reading<f64>, resets_at: Reading<String>}`; a `Reading` is a value or the word `"unknown"`. It carries no timestamp and no Claude name. `BudgetWindowKind { FiveHour, SevenDay }` is the closed window word (serde kebab-case, `five-hour` · `seven-day`; a third word does not deserialize), the `budget-paused` refusal's detail. `Percent` is `nutype` over `u8` with `less_or_equal = 100`, built only through `Percent::try_new`; the two thresholds are `Percent`, the reading's `used_percentage` stays an `f64`.
- `ViolaName`: `[a-z0-9-]`, 1–32 chars, starts with a letter; every `instances/<name>` join and every clap/MCP/channel/SSE name goes through `ViolaName::try_new`.
- `ObsEvent` variants equal the `event` enum in `schemas/diag-line.v1.json` (a tests-owned check asserts it); `a11y-violation` is not a variant.
- The [Error Handling] census of `thiserror::Error` derives names no enum of this crate.

## Crate-specific gotchas
- `detail` for `unknown` is a code word (`viola_core::is_code_word`) or `null`; readers treat an unrecognised code-word `detail` as opaque text, never as an error.
- `unconfirmable` is not a refusal detail; it appears only in an `ok` payload.
