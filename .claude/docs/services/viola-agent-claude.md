# viola-agent-claude

_Crate implementation notes. Primary source: `.andromeda/architecture.md` [Agent Coverage], [CLI Version Compatibility], [Screen Model], [Delivery Confirmation], [Hook Contract], §Conventions (Hook → kind map); security §Input Validation; obs D-14. Generated by `/andromeda-setup-project`._

## Responsibility
The only crate that knows Claude Code. It parses hook payloads tolerantly and maps each hook to a normalised kind. It maps dialog answers to decision bodies (S3 / S7 / S8) and applies the R8 `CLAUDE*` strip. It resolves the npm shim to `claude.exe`, runs the CLI version gate and holds the capability ledger rows (compiled) with their `viola verify` probes. It keeps the vt100 screen signatures (readiness gate), parses the statusline `rate_limits` and `claude agents --json`, and normalises `prompt-submitted` (removes the long-paste wrapper, then reverses tag escaping; classifies `origin` driver/human/harness). No adapter trait yet: a second agent arrives as a sibling `viola-agent-<name>` crate.

## Key integrations

### Consumes from
`viola-core`, `viola-state`; serde_path_to_error 0.1.20 (drift reports → instance detail file only); vt100 0.16.2 (fed bytes by `run`'s pump, always under `catch_unwind`).

### Publishes to
`hook` (decision bodies), the wrapper (normalised events, readiness verdicts, version gate), `list` / `mcp` / `ui` (`claude agents --json` rows), `viola verify` (probes, fixture recorder).

### Dependencies
Tokio banned in its graph.

## Internal conventions
- Decision bodies: PreToolUse `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"allow","updatedInput":{…}}}` (questions incl. `annotations`; plan approve); PermissionRequest `decision.behavior` allow/deny + `message` (plan revise). No decision = exit 0 with empty stdout.
- Security-deciding fields map into closed enums even under tolerant parsing; every external reader bounded by `Read::take(MAX_FRAME)`.
- Ledger rows (S3, S7, S8, R8 strip list, shim resolution, statusline source + shell, harness prefixes, `<pasted_content>` wrapper, modal / input-box signatures, hook tier map, turn end without Stop, dialog concurrency, `claude agents --json` join field, plugin precedence, local commands + post-conditions, tag escaping, largest hook payload) are compiled here, never built from runtime or upstream text.
- An unlisted CLI version → transport-only: types, runs the wheel, emits events, withholds dialog answers (`unverified-cli`).
- The R8 strip is logged as `env_stripped_count` + known names from the compile-time list — never values.

## Crate-specific gotchas
- ExitPlanMode approves only through PreToolUse; PermissionRequest `allow` is ignored for it (measured twice).
- Local commands fire no UserPromptSubmit; `/clear`'s post-condition is SessionStart `clear` + a new `session_id`.
- The fixture recorder rewrites home paths to `~` and usernames to `<user>`; probe prompts are synthetic.
