# Frontend Rules

Path-scoped rules for viola's one built design surface, human CLI output (cli); viola renders no page and has no web-spa surface; the keyboard-driven terminal fleet console tiled on Hyprland (matrix#v2-14) takes its own surface section at the route entry «Console scaffold». Authoritative sources: `.andromeda/design-system.md` and `.andromeda/layout-templates.md`.

## Palette (viola renders no page, so no stylesheet tokens to trace)
- The palette holds eight values; viola renders no page, so no `--c-*` value, role alias, length token or breakpoint is traced.
- Amber means `dialog_pending` only; blue means handoff only. On the CLI handoff blue is never used: link output (`overseer -> builder`) is plain at every depth.
- viola renders no page, so no depth or radius tokens; the cli draws no depth.
- Fonts: the cli's type is the terminal monospace (the user's configured font); viola renders no page, so no font stack is declared.

## Motion (base expression 0.2; no web or graphical frontend, so no frontend expression level)
- At the base expression 0.2 the cli (0.2 on a TTY, 0.0 otherwise) has no motion at all; viola renders no page, so no duration scale applies.

## Components
- viola renders no page, so there are no web components. The six captions NAME · LIVE · STATUS · WHEEL · DIALOG · CLI, their words and slot order are fixed, and the terminal fleet console (matrix#v2-14) reuses them; the readback vocabulary is `open`, `read back`, `unable`, `unconfirmable`.
- Nothing is shown as delivered until read back; `turn-ended` never fills a box.

## CLI surface (`src/cmd/**`)
- Colour decision order (first match → no colour): `--json` · `viola run` · `viola hook`/`mcp` · `NO_COLOR` (present, an empty value included) · `TERM=dumb` · non-TTY stdout. SGR only for amber `DIALOG`, dim `stale` rows, bold NAME — always beside its word; never on `unable` / `fail`. As built (chunk 2026-10-17-cli-output-discipline), `list` is uncoloured under any rung above; on a terminal that takes colour every NAME value is bold, the `DIALOG` word of a wrapped row with a pending dialog takes the attention token (its kind word plain), a wrapped `stale` row is dim from its first byte to its last (NAME dim and bold; on a stale row with a dialog only `DIALOG` amber and not dim), the BAY line, caption, empty-board line and separator carry no SGR, the spans are laid over the escaped, padded cells (the plain board's columns, one write), and the depth is truecolor / 256 / 16 from `COLORTERM` / `TERM` (`COLUMNS`, `CLICOLOR`, `CLICOLOR_FORCE` and `CI` are not read). A wrapped row joined to one `claude agents --json` read by child pid or agent session id reads STATUS `idle` or `busy`, else `unknown`; each unjoined session follows under the `-- UNWRAPPED - READ-ONLY --` line, sorted by name, NAME its `sessionId`, LIVE `live`, `n/a` in WHEEL, DIALOG and CLI, with no separator when there is none and the board as with no `claude` on a failed read. With the terminal's width known (`viola_pty::host_size()`, never `COLUMNS`) only an unwrapped NAME longer than its column (capped at the width less 65) is cut, to the column less 3 characters plus `...`, never inside an escape; a wrapped NAME is never cut, and a piped board or `--json` keeps every name whole.
- stdout = results (`viola mcp` writes only MCP frames, and exits 1 with nothing on stdout or stderr when its home or `diagnostics/` fails `check_path`); stderr = the TTY-only context lines (`waiting:`, the send issue line, `last`'s header), `last`'s `no message` for `null`, refusals `unable  <name>  <reason>  <detail>` (the exit-1 refusals of `run` / `revive` / `verify`, a `verify` stopped by Ctrl-C or TERM before its rows are checked (stdout empty, no summary), `list`'s exit-21 strict-modes refusal, `plugin install`'s exit-21 strict-modes refusal (the home pair, stdout empty; under `--json` the `instance-unreachable` document, stderr empty) `link` / `unlink`'s exit-21 strict-modes refusal of the driven instance (`revive`'s instance pair naming it, stdout empty; under `--json` the `instance-unreachable` document, stderr empty) and the exit-21 strict-modes refusal `send`, `wait`, `last`, `answer`, `pause` and `release` make of their instance before any frame (the same instance pair naming it, not the `[/ ]` mirror, stdout empty, no line written; under `--json` the `instance-unreachable` document, stderr empty) take the fixed form `unable: <text>`) + one `hint:` line (none under `--json`; there exit 21's document `{"v":1,"error":"instance-unreachable","detail":"<cause>"}` names its cause, one of `strict-modes-failed` · `instance-dead` · `unwrapped-name` · `endpoint-lost` · `server-verify-failed` · `socket-dir-refused`, the strict-modes refusals above reading `strict-modes-failed`; every refusal of the start `viola revive` shares with `run` is one stdout document `{"v":1,"error":"<code>","detail":null}` with stderr empty, a `pump_child` error printing none, the child having held the terminal, and an oversize `viola answer` / an unusable `viola send` exit 2 with their fixed `UNUSABLE_RESPONSE` / `UNUSABLE_TEXT` stderr line and no document), errors (under `--json` the `cli` catch site prints `{"v":1,"error":"internal-error","detail":null}` on stdout in place of `error: internal error`, stderr then empty; `run`, `revive`'s start, `mcp` and `hook` stay silent at that site). ASCII only (`->`, `[RB]` / `[  ]` / `[/ ]`, ` - `); no spinner, no redraw, no stack traces, no "done". `viola --help` (and `viola help`) prints exactly `Usage: viola [--home <dir>] <verb> [args]`, the served-verb rows `board:` · `traffic:` · `wheel:` · `handoff:` · `setup:` (`handoff:` holding `link, unlink`, `setup:` holding `plugin install`), then `Options:` (no about line, no clap `Commands:` list; pinned by the `HELP` literal in `tests/cli_output_plain.rs`); per-verb `--help` is clap's usage, unchanged; the hidden `viola mcp` (`#[command(hide = true)]`, no argument but the global `--home`, run only by the plugin, never by a person) appears in no row, and the `HELP` literal is unchanged.
- `list` rows escape every control character (C0 with `\n`/`\t`, DEL, C1) as two-hex-digit escape text (`escape_row`); `wait`/`last` text, and a `link` line's `since` that is no RFC 3339 instant, escape C0, DEL and C1 the same way but keep `\n`/`\t`; nothing is stripped. No hint ever names `viola release`; no hint for `unknown`, `wrapper fault`, `internal error` or a `not-delivered` refusal with an opaque detail or none; a refused `viola answer` ends with its own hint for `unknown-dialog` and, for any other named detail, the hint `viola send` holds for it.
