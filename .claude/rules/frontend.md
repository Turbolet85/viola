# Frontend Rules

Path-scoped rules for viola's built design surfaces, human CLI output (cli) and the terminal fleet console (console); viola renders no page and has no web-spa surface; the keyboard-driven terminal fleet console tiled on Hyprland (matrix#v2-14), `viola console`, is its own surface in the human's terminal, entered on the alternate screen with the cursor hidden and restored on every end, in plain ASCII with no colour bar the editing line of send, switch and open, which echoes its text as typed (UTF-8 included) through row escaping, each scalar 1, 2 or 0 columns wide, re-reading the board once a second and redrawing only when its view changes; its frame floor is 80x24 (at or above it the whole frame from a cleared top-left, `viola console` on row 1 and the key line on the last row; below it one line `viola console needs 80x24; this terminal is <cols>x<rows>`, an unread size counting as 0x0; a line wider than the terminal is cut whole at its columns ending in `...`, never inside an escape, an unwrapped NAME not cut separately, and a fleet taller than the body rows, its scroll window not at the fleet's end, ends in `... <n> more` and one scrolled past its top begins with `... <n> above`), and `q`, Ctrl-C or the end of its input end it with exit 0 from every mode; j, k and the arrows move the selection over wrapped rows, and l last, p pause, r release, f focus, v revive (`viola up`), s send, m switch, a answer and o open each run on the selected row as its CLI verb in a child, one at a time (a static running line standing meanwhile, the verb's own escaped output its result rows), every key bound to nothing in its mode ignored; it draws the fleet as body lines between its title line and its key line, the board's rows in the board's forest order and indent. Authoritative sources: `.andromeda/design-system.md` and `.andromeda/layout-templates.md`.

## Palette (viola renders no page, so no stylesheet tokens to trace)
- The palette holds eight values; viola renders no page, so no `--c-*` value, role alias, length token or breakpoint is traced.
- Amber means `dialog_pending` only; blue means handoff only. On the CLI handoff blue is never used: link output (`overseer -> builder`) is plain at every depth.
- viola renders no page, so no depth or radius tokens; the cli draws no depth.
- Fonts: the cli's type is the terminal monospace (the user's configured font); viola renders no page, so no font stack is declared.

## Motion (base expression 0.2; no web or graphical frontend, so no frontend expression level)
- At the base expression 0.2 the cli (0.2 on a TTY, 0.0 otherwise) has no motion at all; viola renders no page, so no duration scale applies.

## Components
- viola renders no page, so there are no web components. The six captions NAME · LIVE · STATUS · WHEEL · DIALOG · CLI, their words and slot order are fixed, and the terminal fleet console (matrix#v2-14) reuses them and adds a seventh, `LAST`, after them (the age of the instance's newest log line in one unit, `12s` · `4m` · `2h` · `3d`; `unknown` on a wrapped row with no log line, `n/a` on an unwrapped row); the readback vocabulary is `open`, `read back`, `unable`, `unconfirmable`; a live `viola open` prints `<name>  live  <placement>` (under `--json` `{"v":1,"ok":{"name","parent","window","placement"}}`), placement one of the eight closed words `placed` · `refused` · `unplaced` · `unsupported` · `window-unseen` · `unreachable` · `malformed` · `oversize`; a `viola focus <name>` prints `<name>  focused` (under `--json` `{"v":1,"ok":{"name":"<name>"}}`); `viola up` prints one stdout line per instance, `<name>  <word>` or `<name>  live  <placement>` (under `--json` `{"v":1,"ok":{"instances":[{"name","outcome","placement"}]}}`); a `viola switch <name>` prints `<name>  switched  <model> <effort>` and exits 0 (under `--json` one document whose `ok` carries `model` and `effort`), and no window address, pid or workspace is ever printed or logged.
- Nothing is shown as delivered until read back; `turn-ended` never fills a box. A turn ended on an API error shows like any turn end (STATUS `idle`, `wait` reads `turn-ended`, no distinct status, colour or hint); its only trace is one closed cause word of nine in `--json` and MCP `wait` event data, and the CLI's error text is shown nowhere.

## CLI surface (`src/cmd/**`)
- Colour decision order (first match → no colour): `--json` · `viola run` · `viola hook`/`mcp` · `NO_COLOR` (present, an empty value included) · `TERM=dumb` · non-TTY stdout. SGR only for amber `DIALOG`, dim `stale` rows, bold NAME — always beside its word; never on `unable` / `fail`. As built (chunk 2026-10-17-cli-output-discipline), `list` is uncoloured under any rung above; on a terminal that takes colour every NAME value is bold, the `DIALOG` word of a wrapped row with a pending dialog takes the attention token (its kind word plain), a wrapped `stale` row is dim from its first byte to its last (NAME dim and bold; on a stale row with a dialog only `DIALOG` amber and not dim), the BAY line, caption, empty-board line and separator carry no SGR, and after the board and the unwrapped rack a `-- LINKS --` block prints one `<driver> -> <driven>` line per link, sorted, deduplicated and name-checked, with no SGR, absent when there is no link, the spans are laid over the escaped, padded cells (the plain board's columns, one write), and the depth is truecolor / 256 / 16 from `COLORTERM` / `TERM` (`COLUMNS`, `CLICOLOR`, `CLICOLOR_FORCE` and `CI` are not read). A wrapped row joined to one `claude agents --json` read by child pid or agent session id reads STATUS `idle` or `busy`, else `unknown`; each unjoined session follows under the `-- UNWRAPPED - READ-ONLY --` line, sorted by name, NAME its `sessionId`, LIVE `live`, its STATUS, `n/a` in WHEEL, DIALOG and CLI, with no separator when there is none and the board as with no `claude` on a failed read. With the terminal's width known (`viola_pty::host_size()`, never `COLUMNS`) only an unwrapped NAME longer than its column (capped at the width less 65) is cut, to the column less 3 characters plus `...`, never inside an escape; wrapped rows are drawn as a tree, each child under its parent with its NAME cell indented two spaces per depth (the indent counted in NAME's column width), and a wrapped NAME is never cut, and a piped board or `--json` keeps every name whole.
- stdout = results (`viola mcp` writes only MCP frames, and exits 1 with nothing on stdout or stderr when its home or `diagnostics/` fails `check_path`); stderr = the TTY-only context lines (`waiting:`, the send issue line, `last`'s header), a `run` / `revive` start's one automatic-verify line (one write, ASCII, no SGR, only the parsed version and a closed word; none under `--json`), `last`'s `no message` for `null`, refusals `unable  <name>  <reason>  <detail>` (the exit-1 refusals of `run` / `revive` / `adopt` / `open` / `focus` / `up` / `verify` / `console`, a `verify` stopped by Ctrl-C or TERM before its rows are checked (stdout empty, no summary), `list`'s and `up`'s exit-21 strict-modes refusal, `plugin install`'s exit-21 strict-modes refusal (the home pair, stdout empty; under `--json` the `instance-unreachable` document, stderr empty) `link` / `unlink`'s exit-21 strict-modes refusal of the driven instance (`revive`'s instance pair naming it, stdout empty; under `--json` the `instance-unreachable` document, stderr empty) and the exit-21 strict-modes refusal `send`, `wait`, `last`, `answer`, `pause`, `release`, `switch` and `focus` (of its home or instance, before any compositor read) make of their instance before any frame (the same instance pair naming it, not the `[/ ]` mirror, stdout empty, no line written; under `--json` the `instance-unreachable` document, stderr empty) take the fixed form `unable: <text>`) + one `hint:` line (none under `--json`; there exit 21's document `{"v":1,"error":"instance-unreachable","detail":"<cause>"}` names its cause, one of `strict-modes-failed` · `instance-dead` · `unwrapped-name` · `endpoint-lost` · `server-verify-failed` · `socket-dir-refused`, the strict-modes refusals above reading `strict-modes-failed`; every refusal of `viola revive --json` (its strict-modes check, its preflight and the start it shares with `run`) and every start refusal and the not-resumed end of `viola adopt --json` (one of `strict-modes-failed` · `session-live` · `not-resumed` · `already-live` · `stale-heartbeat` · `pinned-hash-mismatch` · `squatted-name` · `socket-dir-refused` · `internal-error`) and every refusal of `viola open --json` (one of `strict-modes-failed` · `already-live` · `stale-heartbeat` · `pinned-hash-mismatch` · `terminal-not-found` · `not-live` · `internal-error`) and every exit-1 refusal of `viola focus --json` (one of `refused` · `unsupported` · `window-not-found` · `unreachable` · `malformed` · `oversize`) and every exit-1 refusal of `viola up --json` (one of `boot-time-unread` · `strict-modes-failed` · `pinned-hash-mismatch` · `terminal-not-found`) is one stdout document `{"v":1,"error":"<code>","detail":null}` with stderr empty, a `pump_child` error of `revive` or `adopt` printing none, the child having held the terminal, and an oversize `viola answer` / an unusable `viola send` / a `--model` or `--effort` after the `--` of `run` or `revive` exit 2 with their fixed `UNUSABLE_RESPONSE` / `UNUSABLE_TEXT` / `PAIR_AFTER_DASHES` stderr line and no document), errors (under `--json` the `cli` catch site prints `{"v":1,"error":"internal-error","detail":null}` on stdout in place of `error: internal error`, stderr then empty; `run`, `revive`'s start, `adopt`'s start, `mcp` and `hook` stay silent at that site). ASCII only (`->`, `[RB]` / `[  ]` / `[/ ]`, ` - `); no spinner, no redraw, no stack traces, no "done". `viola --help` (and `viola help`) prints exactly `Usage: viola [--home <dir>] <verb> [args]`, the served-verb rows `board:` · `traffic:` · `wheel:` · `handoff:` · `setup:` (`board:` holding `list, focus, console`, `handoff:` holding `link, unlink`, `setup:` holding `open, run, revive, adopt, up, switch, verify, plugin install`), then `Options:` (no about line, no clap `Commands:` list; pinned by the `HELP` literal in `tests/cli_output_plain.rs`); per-verb `--help` is clap's usage, unchanged; the hidden `viola mcp` (`#[command(hide = true)]`, no argument but the global `--home`, run only by the plugin, never by a person) appears in no row, and the `HELP` literal is unchanged.
- `list` rows escape every control character (C0 with `\n`/`\t`, DEL, C1) as two-hex-digit escape text (`escape_row`); `wait`/`last` text, and a `link` line's `since` that is no RFC 3339 instant, escape C0, DEL and C1 the same way but keep `\n`/`\t`; the fleet console's human output escapes C0/C1 control characters too; nothing is stripped. No hint ever names `viola release`; no hint for `unknown`, `wrapper fault`, `internal error` or a `not-delivered` refusal with an opaque detail or none; a refused `viola answer` ends with its own hint for `unknown-dialog` and, for any other named detail, the hint `viola send` holds for it.
