# Accessibility Rules

Path-scoped rules for the `viola ui` page and the a11y harness. **Authoritative source:** `.andromeda/a11y-plan.md` §3 (Harness Contract) and §4–§8. Label: WCAG 2.1 AA + SC 2.4.11 + SC 2.5.8 for web-spa only, with the SC 1.4.10 < 760 CSS px exception; the CLI and TUI make no conformance claim.

## Semantic HTML first, ARIA second
- `<html lang="en">`; `<header>` (banner) rendered by `<viola-atis>` with `<h1>VIOLA</h1>` and a native `<dl>`; one `<main>` wrapping racks, tape and announcer; `<h2>` = `WRAPPED`, `UNWRAPPED · READ-ONLY`, `TAPE`; no `<h3>`, no nav/footer/aside/form.
- Racks are native `<table>` + `<caption>` + six `<th scope="col">`. `<viola-session-row>` / `<viola-transfer>` hosts are role-less `display: contents` elements that render native `<tr>`/`<td>` — never `role="row"`/`table`/`cell` on a host, never a role set in `connectedCallback` / `setAttribute`.
- The only ARIA roles: `log` (the tape, with explicit `aria-live="off"` and `aria-labelledby` the `TAPE` `<h2>`) and `status` (one visually hidden `aria-live="polite"` region, present and empty at load, clip-hidden — never `display:none`). No `alert`, no `aria-live="assertive"`.
- Only the readback `.rb` square is `aria-hidden="true"`; the host and its word stay exposed; nothing focusable inside it.
- Tape lines are native `<details>`/`<summary>` — no `aria-expanded`, no scripted disclosure. No `aria-label` where visible text already names the element.

## Announcements (exactly these)
- A strip turning cocked · a readback refusal · `TAPE stopped` · the 401 access strip (instead of `TAPE stopped` after a `viola ui` restart) · 503/404/405 rack strips appearing after first render. Never tape arrivals, stale, `budget-paused`, `expired`, `skipped`, the new-lines count, or recovery. Never the token, URL, `?t=` or a path.

## Keyboard and focus
- Tab order: skip link `skip to tape` (first, visible on focus, `href="#tape-end"`) → every tape `<summary>` oldest to newest → `N new lines below` anchor (only while scrolled up). Strips, captions, markers, ATIS cells and the announcer are never tab stops; no positive `tabindex`; `#tape-end` is `tabindex="-1"`.
- Initial focus stays on `<body>`; no autofocus. No focus movement on SSE arrival, cock/revert, refusal, strips, resume or recovery; trimming and re-render never drop the focused `<summary>`; auto-follow never scrolls it out of view; jumps are instant.
- `:focus-visible` uses `--focus-ring` / `--focus-w` / `--focus-offset`; the sticky header never covers the focused element (`scroll-padding-top`). No single-key shortcuts, no trap.

## Visual
- State is always a printed word (`read back`, `unable · <reason> · <detail>`, `stale`, `DIALOG <kind>`, `expired`, `unconfirmable`, `human`, `unverified-cli`, `budget-paused`); colour is a second cue. Contrast pairs and negative placements per a11y-plan §6; forced colours keep borders, the strike becomes dashed + `unable`, the cock band maps to `Highlight`.
- Text spacing (SC 1.4.12): fixed-height tokens (`--line-h`, `--strip-h`, `--lh-display`, `--lh-label`) must not clip; truncated cells keep full text in the DOM, no `title` tooltips.

## Harness
- axe only through `makeAxeBuilder` in `e2e-web/fixtures/a11y.ts` (tags `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa` + the five best-practice rules by id; rule-execution check after each `analyze()`); specs never call `withTags` / `disableRules` / `options`. Never `bypassCSP`, never an axe `locale`.
- Verdict per state: `violations: []` and `color-contrast` `incomplete: []`; a CSP / Trusted Types console violation fails the test. Test stylesheets and the VSR bundle come through same-origin `page.route` URLs (`/assets/__a11y/*`), never inline.
- Violation rows go to `e2e-web/test-results/a11y/<test-id>.ndjson` (`event:"a11y-violation"`, `process:"ui"`, harness-only, schema `e2e-web/schemas/a11y-row.v1.json`), scrubbed (`url` → path, drop `nodes[].html`) — never into `diagnostics/`.
- Tags: `@a11y`, one `@sc-<id>` per verified SC, path ids `a11y-p1`…`a11y-p5` in titles; no `a11y` suite, no `webServer`, no second browser stack (no Lighthouse / pa11y).
